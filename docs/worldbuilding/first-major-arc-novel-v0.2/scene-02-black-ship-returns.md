# 黑船返航

晏泠第一次看見遠溟三號時，先看見昭黎。

折蘆在東防波堤外只剩一枚被霧含住的黃點，艇首逆浪偏轉，避開秋穗號拖在右舷的殘桅。昭黎站在前纜盤旁，身上的救難服被海水壓成深色。他每次俯身放纜，身影便消失在商船高起的黑船腹後；下一個浪頭過去，他又出現在原處，像那兩年根本沒有離開過她的視線。

晏泠的手按上港務塔窗框。

外灣觀測員正在報告表層潮速、霧牆位置與三盞觀測燈的讀值，她一個字也沒聽進去。她只計算折蘆離防波堤多遠，秋穗號如果在此刻斷掉最後一條桅索，殘桅會從哪個角度掃過救難艇；她甚至記得昭黎不喜歡把防護索扣在右腰，因為右轉時會勾住舵架。

他今日扣在左邊。

這個發現沒有讓她安心，反而使她胸口那一下空得更深。她不在的兩年裡，有別人提醒過他，也可能只是他終於學會不用任何人提醒。無論是哪一種，都表示那段她反覆想像的空白確實發生過。

「審查官？」文書低聲叫她。

晏泠沒有回頭。「折蘆現有退出線？」

「北偏西，貼四號外灣標返回。洛恩已申報秋穗號可拖離。」

「把全程送上主屏。」

主屏映出折蘆尾鏡。影像裡，昭黎以手勢示意秋穗號切斷最後兩股殘索。船員揮斧時，纜繩彈回甲板，折蘆趁船腹抬起的一瞬將拖纜繞過斷桅。洛恩壓低推力，讓商船脫離東側淺礁線。整個動作沒有多餘的半步。

晏泠知道自己應該先看航誌時刻，卻看見昭黎收緊防護扣後，下意識用左手摸了摸右手掌根。

他疲倦時會摸那裡。從前她會把他的手拉過來，替他按開纜繩留下的硬結；有一次他在她床上睡著，右手還握著不存在的舵，她一根一根掰開他的指頭，直到天亮。

「東外環一號觀測燈轉紅。」

塔內有人說出這句話，晏泠才真正聽見周圍。

第一盞紅燈高懸在霧牆上方。它不是風浪警示，也不是敵船入境；那一組燈只監測深潮線方向的界壓。潮生港已經十七年沒在白天看見它轉紅。

緊接著，第二盞也紅了。

港務塔的議論像潮水漫過石階。有人伸手去碰警報鐘，有人要求接通止潮公議署，外貿碼頭的商社代表則在共同線路裡追問是不是儀器故障。晏泠仍看著折蘆。黃色救難燈在霧前太小，像隨時會被第二層黑暗抹掉。

她怕昭黎死。

不是怕一名初級救難員在她主審的事故裡死亡，不是怕封港報告多出一行無法交代的名字。她怕的是那個她曾經用雙手摸過、又親自放開的人，會在她終於重新站到他面前的同一天，沉進一片沒有人能找到屍身的海。

恐懼先於職責，來得又快又難看。她甚至有一瞬想拿起私人頻道，命令他立刻回來；他也許仍會聽出她聲音裡哪一個停頓是真的，也許會像從前一樣先照做，再生氣。

她的手移到通訊鍵上方，沒有按下。

第三盞觀測燈轉紅。

此刻，晏泠才讓自己成為審查官。

她先把害怕放在那裡，不替它改名，再逐項看能證明的事：三座觀測塔分用不同供能，誤差卻在兩息內同向升高；外灣浮標向東南傾，下方錨鏈則向西北拉直；秋穗號已離淺礁，折蘆原定退出線穿過兩種相反的水流；霧牆邊緣沒有隨風移動，反而正以每六息半一次的節奏向港靠近。

這不是單一儀器故障。

「敲長鐘。」她說。

值勤官轉過來。「封港要由港務長或兩名事故官共簽。」

「我不是在下封港令。先依不明外灣壓力啟動長鐘警示，所有非救難船停槳降帆。把我名字記在發令人欄。」

「另一名事故官還在西城。」

「所以封港尚未生效。長鐘現在生效。」

第一聲長鐘從塔下撞出去，穿過滿港帆索與屋脊。秋穗號上的斧聲停了，內港一排排帆布依序落下。各國租用碼頭降旗待命，瀾國巡航艇從內水啟動，先守住通往城區的三條水道。

長鐘沒有讓港口真正靜下來，只把所有人的急事壓到同一個時刻。糧駁要求在封線前卸下今日配給，客船上有人必須趕去西城見垂危親人，外貿碼頭則有三十箱離冰便會壞的藥。每一條線都說自己不能等。

晏泠沒有讓值勤員只回覆「封港規定」。她命糧駁原位封艙，由瀾國倉務員與承國記貨人隔水共同點數；讓客船把緊急名單送醫療席，若親屬確實垂危，先開單向傳訊而不是放人進城；易壞藥箱移上租用碼頭高架棚，貨主可遠距監看，港警不得藉封鎖查閱商業封記。

南泊代表在共同線路裡說：「你們困住我們的貨，卻不保證賠償。」

「封港令只能決定現在不能移動，不能預先免除瀾國該負的損失。」晏泠說，「把停工時刻、貨況與每一次拒絕移運的命令留下，之後逐筆算。」

「若判定只是儀器誤報？」

「那也不會把今日退還給你們。」

她知道這些安排會使報告變厚，也會讓港務府在事後賠出一大筆錢。可封港若只記住防波堤，便會忘記堤內每個被命令停下的人仍在過日子。昭黎早晨漏掉的十三分曾讓一批藥受潮；她不願把整座城的等待寫成一句「因安全需要」。

文書將民生處置另開一頁，晏泠在發令人欄簽名。她的筆尖沒有停，直到看見客船緊急名單第一行寫著「剩餘時刻不明」。那幾個字令她再次望向外灣。昭黎也正在一個誰都無法保證剩餘時刻的地方，而她不能給他比其他人更多的時間，只能確保每一個被奪走的選擇都留下理由。

晏泠把共同頻道分成兩層。瀾國港務線處理城內、泊位與疏散準備；止潮公議署只能在歸潮灣與外環錨點提出檢疫建議。她沒讓任何一名外國代表越過港務線直接命令折蘆，也沒因潮生港是瀾國領土便拒絕外環數據。

「折蘆，回報可中止點。」

洛恩的聲音從風裡傳來：「秋穗號殘桅已脫離破船角，拖行還需二十息；現在放棄，商船會重新橫漂，但船員可自行處理。」

畫面裡昭黎抬頭看了一眼霧。晏泠知道他在算那二十息值不值得。她也知道他最危險的地方從來不是不怕死，而是他總能替別人的損失找到足夠好的理由，然後把自己的生路從算式裡拿掉。

「完成二十息。」她說，「之後折蘆沿北線退回，不得接近霧牆。」

昭黎的聲音切進來：「北線下層潮向西北，會把船尾推向秋穗號。申請改走原東標線。」

「原線界壓上升，未獲准。」

「那裡表層退潮仍向外，折蘆能借流轉向。」

「你只能證明表層。」

頻道停了一息。昭黎沒有叫她名字，也沒有問她是不是又要替他決定。他只說：「收到。二十息後再報。」

那種公事公辦比質問更讓她難受。

霧牆裡先出現一點青白色的光。

它亮起時，周圍霧氣向外鼓開；熄滅時，海面像被一隻看不見的手往下壓。第二次亮起，光沿著巨大船首的接縫爬行，照出焦黑木材、鉚接金屬與一種灰色異質物。第三次亮起，一艘沒有旗、沒有船籍燈的黑船從霧裡完整露出，逆著表層退潮向歸潮灣移動。

塔內沒有人說話。

遠溟三號這個名字當時還無人知道。他們只看見船腹有長年高壓留下的變形，甲板上沒有活動人影，斷桅卻朝違反水流的方向滴水。每一次青白光脈動，黑船便往港口近一段；像海不是在推它，而是岸上的某樣東西正在回答它。

昭黎先開口：「黑船周圍出現兩層潮。表層向東南，下層向西北，分界深度不定。折蘆申請先向北切兩船長，再回港。」

值勤官看向晏泠。那條路最短，卻會讓折蘆從黑船與秋穗號之間穿過。若黑船再一次脈動，下層潮可能把兩艘船同時擠在一起。

「駁回。」晏泠說。

「替代線？」

她把外灣圖放大。可用的回港水道只剩四號標內側，然而那條線即將被巡航艇封上。只要晚半刻，折蘆便不能回內港，只能沿隔離外環轉往歸潮灣。

她可以拖延封線。

只要說巡航艇尚未完成位置確認，只要讓值勤官把命令晚送十息，昭黎就能搶進來。沒有人會知道那十息是失誤還是猶豫。等他靠岸，她可以再把他隔離、問訊、甚至親自罵他不該冒險；至少他會在她碰得到的地方。

外灣水位忽然整片下降。黑船青白光熄滅，折蘆被看不見的斜流扯向北側，秋穗號則向相反方向偏。昭黎立即放鬆拖纜，讓兩船各自滑開；他的動作救了商船，也把折蘆送得更靠近黑船。

晏泠胸口那個恐懼再次抬頭。

她把巡航艇的位置、黑船速度與折蘆剩餘推力寫在同一張圖上。若讓昭黎此刻回內港，不只是他一個人越過未完成的污染判讀；折蘆船底、拖纜、兩名艇員與所有接觸過秋穗號的人都會沿主水道進城。黑船若能藉固定物定位，折蘆還可能把異常潮帶過防波堤。

判斷沒有因她愛過他而改變。

她按下四號水道封閉鍵。

「巡航二艇，橫封四號內線。折蘆取消返回內港資格，指定歸潮灣中層檢疫棧橋為唯一目的地。」

值勤官吸了一口氣。「折蘆還在封線外。」

「我知道。」

「命令一落，他們沒有退路。」

「留下來的不是退路，是把未知帶進城的入口。執行。」

巡航艇在主屏上轉向，灰白船身橫進四號水道。那艘艇的駕駛原本只需要照自動封港程序，晏泠卻拿起直通片，親自報出攔截角度，修正到能擋住折蘆、又不讓巡航艇進入兩層潮的位置。

昭黎立刻看懂了。

「四號線是你封的？」他問。

共同頻道裡有十幾個人在聽。晏泠望著他縮小在畫面裡的身影，說：「命令由航安事故審查官晏泠簽發。折蘆不得返回內港，重複，不得返回內港。」

她沒有說對不起。那三個字既不能淨化船底，也不能把被她切斷的水道還給他。

昭黎沉默兩息，手已經轉動纜盤。「折蘆收到。申請秋穗號自行返港，我艇轉歸潮灣。」

「准。」

「兩名艇員是否可以轉巡航艇？」

「不行，接觸鏈必須完整。」

「收到。」

每一個回答都很短。晏泠從他的站位看見他在生氣：壓力越大，他越少話，右手會把同一個鎖銷檢查兩遍。他仍照她的命令轉向，也仍把兩名艇員留在自己視線裡，沒有拿他們替自己多爭一條路。

第二名事故官終於接入，封港雙簽成立。港鐘連響九聲前的準備開始：商船原位拋臨時錨、內港醫療棧橋轉為清潔線、歸潮灣外環固定錨待命。止潮公議署要求接管所有外海通訊，被晏泠拒絕；她只開放觀測副本與檢疫建議欄，城內命令仍由瀾國港務府發布。

「黑船右舷有脫落物。」觀測員忽然說。

主屏上，一艘小型救生艇從黑船破口滑下。艇裡伏著一個人，沒有帆槳，也沒有燈。它先被下層潮帶向西北，接著沿黑船周圍凹陷的海面倒退，艇尾朝破口撞回去。

折蘆是最近的船。

昭黎幾乎同時回報：「發現生還者。申請救援。」

值勤官看晏泠的眼神近乎不忍。依現行程序，未知返航物出現人員時，應先由無人浮囊確認生命徵象，再等檢疫艇進場。最快也要半刻，而救生艇不到二十息就會撞回黑船。

晏泠盯著那個伏在艇裡的身影。她已經為公共安全切斷昭黎的退路；現在他被困在封鎖外，反而成了唯一來得及救人的人。

她不能因為怕失去他，便把另一個人的命從畫面上刪掉。

「提出不接觸黑船的方案。」她說。

昭黎把測流線與沉墜圖傳回。「浮囊送纜，沉纜從救生艇下方轉向，只勾船尾斷樁。折蘆不碰黑船，人員不下水。兩層潮下一次重合約六息，誤差半息。」

「假設來源？」

「三次脈動間隔，尚未證明穩定。」

他沒有把推測說成把握。晏泠在救援欄標上條件，讓洛恩覆核，並要求遠端醫療同步接管。所有程序都指向同一個結果：可以試一次，失敗便撤。

她簽下准許。

「折蘆可執行單次拋纜。不得登黑船，不得越過救生艇外側警戒標；兩層潮間隔偏差超過半息立即中止。」

昭黎說：「收到。」

他走向拋纜弩時，沒有再看港務塔。晏泠卻看見他在戴手套前，左手又按過右掌根部。那個動作使她想起許多不該在公務頻道裡存在的清晨。

她將自己的封線命令拉到紀錄最上方，親手補上理由：審查官知悉折蘆主舵者為未申報成年舊交；命令依兩層潮接觸風險成立；私人關係可能影響判斷，請後續覆核。

文書看見那行字，呼吸停了一下。「要現在寫？」

「現在不寫，之後每一個正確理由都會被懷疑是補的。」

她在末尾簽名，印泥沾上拇指。遠處，昭黎抬起拋纜弩，救生艇正被黑船陰影一寸寸吞回去。

塔窗上映出她的臉，蒼白而陌生。她沒有避開那道倒影，只把沾墨的拇指壓進掌心，直到下一道命令需要它。

封港令已經落下，四號水道也已由她親手切斷。無論下一箭救回誰，昭黎、折蘆與那艘黑船都被收進同一條事故責任鏈；而她的名字，會永遠留在他失去退路的那一頁。
