# 第 05 幕　第一座回答的錨

午夜以前，歸潮灣的五座固定錨都只做一件事：把海與岸分開。

它們沿外環立在水下石脊，白色光柱落向海床時，界壓會被推回深潮線方向；返航船依燈位進入檢疫走廊，巡航艇依燈位知道哪一寸水不能跨。兩百年來，港務手冊把固定錨寫成堤、尺與鎖，沒有一頁說它會聽。

第一座錨改變節奏時，晏泠正在重看自己切斷四號水道的紀錄。

她在「知悉折蘆主舵者為未申報成年舊交」那行停了很久。審核者已把「舊交」改註為「舊情」，用字來自彌菈的界線表。那兩個字比她原先寫的更準，也更難藏。她可以提出異議，要求在正式判定前使用中性稱呼；但她若連名稱都要迴避，後面每一項正確決定便會像精心修飾過的謊。

窗外傳來一聲低鳴。

第一座錨平日每十二息校準一次，聲音短而平。這一次卻是四聲長鳴、一聲短鳴，停六息，再四長一短。

晏泠抬頭。

遠溟三號停在檢疫外泊，整艘船沒有風帆也沒有可見推進，船腹青白光正在用同樣節奏明滅。

四長，一短。

第一座錨又答了一次。

不是共振。共振會有延遲與衰減，眼前兩組節奏卻愈來愈齊；黑船亮起，錨點在下一息鳴響，第二輪只差半息，第三輪已縮成同一個節拍。水面浮標隨每次回答向岸偏移一掌，像海底有一條看不見的線正在被兩端輪流收緊。

晏泠按下總警報。「停止第一錨主動輸出，切被動觀測。其餘四錨不得跟隨同步。」

控制席回報：「第一錨拒絕降載。不是系統鎖定，輸出值在自動校準範圍內。」

「手動斷開校準迴路。」

「那會在外泊東側留下缺口。」

「先標成待決，不執行。把原始波形送伊嵐與歷史檔案席。」

她不想因為害怕便把燈全部熄掉。固定錨保護的不只是遠溟三號外側，還有秋穗號、折蘆與三十七艘來不及撤離的商船；任何一座突然失壓，都可能把兩層潮推進內港。她也不想因為手冊沒寫過回答，便假裝那節奏只是設備雜音。

主屏拉出歸潮灣即時位置。折蘆不在中層棧橋。

晏泠的指尖驟然冷下來。「折蘆位置？」

值勤員調出證物作業線。「右舷纜盤溫度異常，需要移至外側清洗浮台拆檢。洛恩的引航牌暫扣，由昭黎以事故見證人身分陪同封存員，作業已在十七息前開始。」

「誰准他上艇？」

問得太像私人質問。晏泠聽見自己的聲音，立刻修正：「誰核准事故接觸者離開醫療休息區？」

「彌菈解除持續觀察，但維持暫停獨立操船。他不是主舵，只核對纜盤拆封。瀾國港警與公議署封印員都在艇上。」

畫面找到折蘆。救難艇正停在第一錨與第二錨之間的維修水道，距中層棧橋不到三百丈。平時那裡是最安全的短路，兩側錨點能把任何漂入物壓在固定走廊；如今第一錨每回答一次，走廊的水便向黑船收窄一分。

折蘆身後，內側隔離閘已因警報落下。前方，第一錨的白光與遠溟三號青白光在水面交成一條明亮窄帶。

昭黎被夾在裡面。

晏泠的身體比判斷更早記得失去。他兩年前離開她住處時，也只帶走一只窄包，門闔上前沒有回頭；她站在原地，直到聽不見腳步，才發現自己始終抓著那枚準備遞給他的伴侶登記片。後來她把那張片撕碎，告訴自己選擇港務職是為了更大的責任。可責任沒有讓記憶變小，只使她更擅長在害怕時站直。

「折蘆，回報船況。」

昭黎的聲音傳來，背景全是纜盤急轉的高鳴。「推進正常，右舷證物艙已鎖。第一錨每次回應，水道北側流速增加兩成；內閘關閉，前方白帶不明。建議原地保持。」

他一如往常先報可執行事實，沒有說自己受困。

晏泠把他未說的部分補進自己的判斷。原地保持只適用於節奏不再縮短；一旦第一錨與黑船完全同步，折蘆可能成為兩者間的固定參照物。退出內閘需要解除封鎖，向前則要穿過白光走廊。兩條路都不是手冊允許的路。

「艇上由誰主舵？」

「港警值勤舵手。」

「昭黎不得接舵。」

頻道停了半息。「收到。」

她知道他會因此生氣。她也知道，在利益衝突已被寫下後，任何讓昭黎接管的臨時授權都必須有比「他最熟悉折蘆」更完整的理由。

第二座錨開始低鳴。

最初只是一聲，接在第一錨之後；下一輪變成兩聲，像尚未學會完整詞句的孩子。遠溟三號明滅，第一錨四長一短，第二錨跟上一長。第三座錨的輸出值也出現微幅上升。

伊嵐·拓衡從觀測線接入。「先說結論：不能再把固定錨視為被動屏障。推測是黑船以節奏詢問位置，第一錨的校準機制把規律訊號判作待修正偏差，因此主動回傳。每次回傳都讓兩者取得更精確的相對距離。」

「證據強度？」晏泠問。

「第一錨波形與黑船脈動相關九成二；『詢問位置』只有推測。可以證明的是，它們正在縮短反應時間。」

「折蘆在兩錨之間會發生什麼？」

「不知道。最壞情形是成為新的中繼參照；較輕情形是船體承受兩次相反界壓。兩者都不適合等。」

控制席提出第一方案：全熄五錨，讓折蘆從外側繞回。港務席立即反對，外泊船群會失去隔離屏障，兩層潮可能直抵防波堤。第二方案是維持錨點，派無人拖具穿越走廊；伊嵐指出任何固定頻率都可能成為新的回答。第三方案是打開內閘，讓折蘆回到中層棧橋，但封鎖規則要求先證明艇身沒有新增污染，眼下無法完成。

每一個方案都把風險交給不同的人。沒有一個能把風險消除。

晏泠調出封鎖規則原文。緊急救援窗口不等於解除封港：當隔離區內人員面臨立即生命危險，事故官可在不連通清潔區的前提下，開啟單一閘門、單向通行、最短時間，並將通行終點限制在另一污染節點。原本這條規則用於火災或醫療撤離，從未用於一艘可能攜帶未知界壓的艇。

內閘後方不是潮生城，而是已清空的舊清洗灣。只要同時關閉清洗灣另一端，折蘆即使進門也仍留在污染區。

「可開內閘十八息。」晏泠說，「折蘆單向進舊清洗灣，外閘與城側水門維持關閉。第一錨不斷電，只暫停自動校準一輪；第二錨降到不跟隨輸出的最低載。艇進灣後立刻關閘，所有人重新計入接觸鏈。」

值勤官說：「緊急窗口要證明立即生命危險。折蘆現在船況正常。」

「反應間隔由六息縮到三息半，第二錨已開始模仿，白帶寬度每輪增加一丈。以目前速率，三輪後覆蓋折蘆位置。」

「那是模型。」

「是可由原始值覆核的模型。把不確定性一起寫。」

止潮公議署代表要求否決。「暫停校準可能讓遠溟三號脫離現有固定，黑船比三名艇員更大的風險。」

晏泠盯著他。「你們可以反對瀾國打開通往城區的水門；這扇門不通城，只連接瀾國已劃入污染區的舊清洗灣。公議署有共同錨點建議權，沒有接管潮生港人員救援的權力。」

「錨點是盟約設備。」

「所以降載需要共同見證，不需要你單方准許。把反對意見留下。」

她讓文書建立緊急窗口草案。寫到「受救援者」時，昭黎的名字排在第一個，後面是舵手、封印員與兩名港警。晏泠沒有把他的名字移到中間，也沒有只寫「折蘆五人」來讓自己看起來更中立。

第二事故官從西城接入，讀完方案後問：「由誰主張立即危險成立？」

「我。」

「你與昭黎的關係已被標記。」

「是。」

「你是否因私人關係提高風險判定？」

整條共同線路都安靜下來。從前的晏泠會回答所有人都依同一標準，像否認差異便能保住判斷。此刻她看著主屏上的折蘆，那艘小艇正被兩道光一寸寸壓窄退路。

「我害怕他會死。」她說，「這可能使我傾向提早開窗。因此請你覆核立即危險數值，請伊嵐公開模型，並由不同值勤員執行閘門。但方案不因我害怕而自動錯誤。」

她沒有說愛，也沒有請求體諒。她只把會影響判斷的東西放進紀錄，讓別人有權反對。

第二事故官逐項讀過流速、白帶寬度與同步間隔。「立即危險成立。窗口條件過窄但可執行，我共同簽署。若第一錨暫停失敗，立刻中止，不准延長。」

伊嵐補充：「十八息是上限，不是目標。折蘆進閘後，即使有人落水也不能重開同一節奏，避免形成第二次回答。」

「寫入。」晏泠說。

昭黎從頻道裡聽完所有內容。他沒有趁她承認害怕時說任何私人話，只問：「舊清洗灣水深？」

「東側二丈一，西側淤積不明。」

「折蘆進門後要右轉，船尾會靠淤積側。申請把開窗延到二十息，或允許我接舵。」

晏泠閉了一下眼。他果然會把「我最會做」當成最短答案。

「開窗不延長。值勤舵手保持主舵，你可以站在可見位置報角度，不得碰舵柄。若他判斷不能執行，窗口取消。」

「我對折蘆偏轉更熟。」

「所以你報，讓他決定是否採用。」

昭黎停了兩息。「收到。」

那兩息裡可能有怒意，也可能有他不肯說的其他東西。晏泠不替他猜。她只知道這一次救他不能又變成把所有決定交還給他。

窗口倒數開始。

城側水門先落鎖，舊清洗灣人員清空，醫療隊退到透明牆後。第一錨控制席解除一輪自動校準，第二錨降載。四長一短的鳴聲突然缺了一拍，遠溟三號青白光在海面上停頓，像某個問題沒有立刻得到答案。

「開內閘。」

鐵閘從水下抬起。折蘆推進全開，船首朝窄門切入。

「右舵六分。」昭黎報。

值勤舵手回：「右六。」

第十五息。

第一錨重新尋找校準值，白光在折蘆船尾掃過。救難艇忽然左偏，右舷證物艙幾乎撞上閘柱。

「回正兩分，船尾讓淤積帶托。」昭黎說。

舵手沒有立刻照做。「水深不明。」

「折蘆空載偏左，證物艙在右，淤泥碰的是左尾，不會卡推進。」

「依據？」

「今日離泊、救生艇拖行與清洗後吃水，三次都記在原始航誌。」

舵手回正兩分。折蘆左尾擦過淤積帶，船身被軟泥托了一下，右舷恰好避開閘柱。

第九息。

第二錨輸出忽然反彈。伊嵐喊：「它在追第一錨缺掉的節奏，窗口提前結束！」

按規則，此刻應關閘。折蘆船首已進舊清洗灣，船尾與兩名站在後甲板的人仍在門外。立即關閉可能直接把艇身夾斷。

值勤官的手停在關閘鍵上。「關會撞船。」

「保持原倒數。」晏泠說。

「伊嵐要求提前。」

「她要求的是窗口結束，不是用閘門切船。第一錨維持失步，不新增降載；折蘆還需四息。把這四息記為偏離條件。」

「這不是原核准方案。」

「不是。執行人是我，偏離責任寫我。」

她的印按上即時紀錄。墨色還沒乾，第二錨已發出三長一短，遠溟三號隨之亮起。水道白帶向閘門猛推，折蘆船尾像被巨浪擊中，整艘艇往前竄。

昭黎抓住欄杆，沒有碰舵。值勤舵手把推進壓到極限，折蘆終於完整越門。

「關閘！」

鐵閘落下，白光撞在外側水面。舊清洗灣裡的水高高湧起，拍上透明牆，又被關閉的城側水門擋回。折蘆在狹灣裡轉了半圈，船首擦過緩衝木，停住。

晏泠先數人。舵手、封印員、兩名港警都在；昭黎從後甲板站起來，左額被欄杆撞出一道血痕，仍先朝艇內點名。五個回答依序傳回，沒有少。

她握著通訊片的手這才開始發抖。

「折蘆保持原位。」她說，「所有人重新檢疫，不得越過城側門。昭黎，你的額傷由醫療席判斷，不准用還能工作回答。」

共同頻道裡有人極輕地咳了一聲。那句話顯然不像事故官會對普通救援者說的話。

昭黎隔著主屏看向港務塔方向。「收到，審查官。」

他沒有叫她晏泠，也沒有讓那個過度熟悉的提醒變成兩人共享的秘密。

危機沒有結束。第一錨恢復校準後，四長一短再次響起；第二錨已能回答三長一短，第三錨也出現第一個長音。伊嵐要求立即封存所有波形，晦岑的歷史席則傳來一份兩百年前手寫警告：固定錨原本用於讓迷航者辨認岸線，後來才改造成封界設備；它們保留了回應規律訊號的舊構造。

錨不是單純的牆。

它曾經被造來回答海上來的問句。

晏泠建立新事故項目：固定錨回應遠溟三號節奏，可能暴露潮生港相對位置；第一錨已完成多次回答，第二與第三錨出現模仿；推測與未知部分另列。她把緊急窗口的十八息、提前失敗、額外四息偏離與自己下令不關閘的決定全部附上原始值。

文書低聲問：「最後四息若寫成艇身通行所需，不必標偏離，仍能解釋為原窗口的一部分。」

那樣紀錄會更乾淨，她也可能不必接受越權審查。

晏泠看著舊清洗灣。昭黎已坐上臨時檢查凳，彌菈隔著防護線處理他額角。他似乎還想回頭看折蘆纜盤，彌菈用一根手指把他的下巴轉回去。他沒有笑，卻也沒有再抵抗。

「原方案明定條件失敗即中止。」晏泠說，「條件在第九息失敗，我決定維持四息。照實寫。」

「理由？」

「立即關閘將造成可預見的艇身夾斷與人員死亡；維持四息增加錨點同步風險。我選擇前者，因為當時仍可禁止折蘆通往清潔區，且新增風險可被觀測。註明我與昭黎的舊情，交獨立席覆核是否影響比例判斷。」

她逐字念，文書逐字寫。沒有一句否認，沒有一句請求原諒，也沒有把救下昭黎說成某種足以抵銷風險的功勞。

遠溟三號又亮一次，第一座錨隨即回答。這次港務塔裡所有人都聽懂了那不是回聲，而是一條正在往岸上縮短的路。

晏泠在窗口紀錄末尾簽名。她的字一向平直，最後一筆卻因手抖略微向下。她沒有重簽，也沒有換一張更好看的紙。

昭黎已經脫困，潮生港卻從此多了一份不能撤回的證據：固定錨會替海上的問句回答，而晏泠曾為了救一名與自己有未申報舊情的救援者，合法打開十八息窗口，又在條件失敗後親自多留四息。

那四息日後可以救她，也可以定她的責。她第一次不靠否認保護兩人的關係，只把恐懼、理由、選擇與代價寫在同一頁上，讓任何人都能看見。
