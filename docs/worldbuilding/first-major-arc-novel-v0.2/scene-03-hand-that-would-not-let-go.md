# 第 03 幕　不肯鬆開的手

昭黎扣下拋纜弩。

弓臂在掌下猛震，綁著黃標的浮囊越過兩道相反的水紋，落在救生艇外側。表層退潮立即把浮囊向東南帶，下方沉墜卻拉著細纜往西北切，繩索在水裡彎成一個看不見的鉤。

「浮纜快半息。」洛恩說。

昭黎已經鬆開纜盤。多放出去的兩臂繩長被表層潮帶走，沉墜從救生艇下方繞過，第一次擦過船尾斷樁，滑了。黑船青白色的光正沿船腹接縫往下熄，周圍海面隨著暗下去的節奏凹陷。

救生艇開始倒退。

它裡面那個人仍伏著，一隻手垂在艇沿，指尖隨船身顛簸碰水。昭黎看不清那隻手是否還有力氣，只看得見黑船破口愈來愈近。焦黑船板像一張沒有牙齒的口，等著把掉出來的人重新吞回去。

「收浮囊，留沉纜。」昭黎說。

船首艇員碰上收纜桿，洛恩立刻喝止：「聽清楚，他要的是浮盤！」

兩座纜盤只差一臂。艇員改握左桿，浮囊收緊，沉纜仍順下層潮繞行。第二次，網圈從救生艇底部浮上，纜股咬住那根未斷乾淨的尾樁。

「中。」

話音未落，海面像被抽走支撐。折蘆與救生艇同時往低處滑，纜線瞬間繃直，救生艇尾樁發出尖銳裂響。

昭黎的右手壓在纜煞上，沒有鎖死。「讓它走半臂。」

「再走會碰船。」艇員說。

「現在鎖，斷的是尾樁。」

他感覺纜繩的震動透過煞柄鑽進掌骨。救生艇被黑船附近的回流拖得更快，折蘆船首也向北偏；兩層潮沒有單純的上與下，分界正隨青白光脈動，像兩片互相錯動的玻璃。任何一個角度算錯，救生艇會撞船，折蘆也會被自己的纜拖進黑船陰影。

第三息，沉纜擦過折蘆右舷。

第四息，救生艇只剩兩丈便進破口。

第五息，黑船最下方那線青白光完全熄滅。

昭黎喊：「鎖，左滿舵！」

纜煞咬合，折蘆的雙推進同時全開。下層潮把沉墜向西北送，折蘆則借表層潮往東南轉，兩股力量把救生艇從黑船船首前橫扯過去。艇底刮過一片焦黑碎板，聲音尖得讓人牙根發酸；黑船上方落下一串鏽水，最近的一滴砸在折蘆外側甲板，立刻被標記燈圈成紅色。

昭黎沒有去看那滴水。

救生艇越過警戒標時，尾樁又裂了一半。昭黎跳離纜煞，抓起備用短索，先扣折蘆主環，再把繩尾交給船首艇員。

「不准跨紅線。長鉤套艇首，我套船尾。」

港務塔的共同線路裡傳來晏泠的聲音：「昭黎，回舵位。」

她叫了他的名字，不是職稱。

頻道安靜了一瞬。昭黎抬頭，港務塔遠得只剩灰色輪廓，他看不見她的臉，只聽見紙筆在收音器旁碰落桌面的脆響。

下一刻，晏泠重新開口：「更正。折蘆主舵者不得離開安全索範圍。現場由洛恩判斷人員配置。」

洛恩把自己的安全扣壓上昭黎背帶，又拉了一次確認。「他在範圍內。繼續。」

昭黎沒有時間分辨胸口那一下是因為她失態，還是因為她立刻把失態改回紀錄。他用長鉤勾住救生艇尾環，短索套上時，艇內的人突然動了。

先是垂在水面的手收回去，接著一雙眼從散亂的濕髮後睜開。

女人縮在艇底，身上套著一件不屬於任何五國制式的灰白航衣。她的左肩有大片乾涸血跡，兩腕與頸側覆著細長白痕，像皮膚曾被某種看不見的線一層層勒過。她醒來後沒有看折蘆的人，而是先看黑船、纜線和每一條能離開的水路。

「聽得懂瀾國通用語嗎？」昭黎問。

女人的目光這才落到他身上。她沒有回答。

遠端醫療線接入，一個冷靜的女聲說：「我是檢疫醫官彌菈·森。不要徒手接觸。隔離罩到位以前，任何人不能跨越兩船紅線。先問她能不能呼吸，有沒有胸痛。」

昭黎蹲在救生艇外一臂遠的位置，讓自己的手留在女人看得見的欄杆上。「你能呼吸嗎？」

她的胸口起伏很淺。過了兩息，她點了一下頭。

「胸口痛？」

她又沉默，右手卻按住肋側。

「我把這當成可能疼痛，不當成回答。」昭黎對醫療線說。

彌菈回道：「記錄可能疼痛。下一步要固定兩船，隔離罩會從上方降下。先告訴她。」

昭黎把每一個動作說得很短：長鉤不碰她，只碰船；透明罩會遮住天空，但兩側看得見；他們不會把她帶回城內，只去歸潮灣檢疫棧橋；如果她不想被誰碰，可以用手指、搖頭或說話拒絕。

女人一直盯著他的嘴，像在確認話與動作會不會一致。

第一支長鉤套住艇首時，她全身一顫，手摸向腰側。那裡只剩一個空鞘。艇員本能地抬起防護叉，昭黎立刻把手掌朝下。

「放低。她沒有武器。」

「她在找武器。」

「找不等於攻擊。」

防護叉下降半尺，女人的視線跟著叉尖移動，肩背仍緊貼艇壁。昭黎將自己的救難刀連鞘解下，放到身後甲板，沒有踢進她碰不到的水裡，也沒有遞給她。

「我的刀在這裡，不會拿來碰你。」

她看了刀一眼，再看他空著的兩手。

隔離罩從折蘆吊臂緩緩降下。透明罩的影子掠過女人臉上時，她忽然急促吸氣，右手撐住船底想站起來。救生艇一晃，她膝蓋失力，整個人往艇沿撞去。

昭黎伸手到一半，停住。「可以扶你嗎？」

她看見他的手，猛地搖頭。

昭黎把手收回欄杆，改用肩膀抵住兩船間的緩衝墊，讓救生艇不再晃。「不扶。你抓船邊。」

女人用兩隻手攀住艇沿，白痕因用力浮出紅色。彌菈要求罩子停止下降，給她看清四面。等呼吸慢下來，昭黎再問：「要罩子繼續嗎？點頭是繼續，搖頭是停。」

她盯著罩子頂端，終於很輕地點頭。

四枚底扣依序合攏。最後一枚落下時，黑船青白光再亮，外環第一座固定錨也在遠處升起一道細白光柱。兩層潮短暫重合，折蘆猛地一沉。女人像被那道光刺中，左腕白痕裂開，血從袖口漫出。

彌菈立即下令：「停止所有非必要探測。罩內只保留呼吸與脈搏被動讀值。」

觀測塔有人反對：「我們需要確認返航者與錨點反應。」

「你要確認的是錨，不是用她的疼痛替你做訊號燈。停掉主動束。」

昭黎聽見幾個設備依序關閉。女人仍縮在艇底，目光越過他肩膀，看著五座待命錨點的方向。她的嘴唇動了一下，發出的聲音乾得像磨過鹽。

「不要……全亮。」

「哪一座會傷你？」昭黎問。

她立刻閉口。

昭黎沒有追。「收到，不再問。」

共同頻道另一端，晏泠說：「此句涉及港口風險，應請她說明——」

話到一半停住。昭黎聽見晏泠吸氣，接著聲音變回精確的公務語調：「更正。請醫療席判斷是否適合繼續詢問。」

彌菈回答：「不適合。原話記錄，推測另列。」

昭黎把女人的那句話寫進折蘆航誌，沒有補上自己的猜測。筆尖離紙時，救生艇裡傳來一聲極輕的「喀」。女人正用指甲敲艇壁，四長一短；停一息，又四長一短。

「繫帶節奏？」洛恩問。

昭黎看向她腰側。灰白航衣上有幾條斷裂固定帶，扣環的磨痕顯示它們曾長時間以同樣節奏受力。她也許在重複船上的某種訊號，也可能只是用熟悉的動作讓自己保持清醒。

「先記，不解釋。」他說。

折蘆拖著救生艇轉向歸潮灣。內港入口已被晏泠切斷，他們只能沿封鎖外緣前進。固定錨一座接一座亮起，每亮一座，女人的白痕便更紅一分。到第三座時，她開始發抖；到第四座時，她忽然朝透明罩外伸手。

離她最近的是一名穿白色防護衣的醫療艇員。艇員依訓練把戴著雙層手套的手送到罩內接觸孔旁，問：「我可以替你固定手腕嗎？」

女人看見白色袖口，整個人向後撞。她搖頭，動作大得後腦碰上艇壁。

艇員停手。「好，不碰。」

另一名救難員試著把軟墊從側邊推進去，她也立即踢開。她不是聽不懂拒絕，也不是失去判斷；她清楚知道哪些東西、哪些人不能靠近。

昭黎把剛才記錄節奏的筆放下，移到罩子正面，仍保持一臂距離。「你要我留在這裡嗎？」

女人的目光黏在他臉上，沒有點頭，也沒有搖頭。

「我不靠近。你若要我走，指門。」

她看向罩子的檢修門，手指沒有抬起。

第五座錨點亮起前，遠溟三號忽然整艘暗下。女人從艇底撐起身，像聽見某個只有她知道的聲音。她先看黑船，再看昭黎，嘴裡吐出一串他聽不懂的音節。隨後她的膝蓋一軟，額頭撞向罩壁。

昭黎再次伸手，仍先問：「可以接住你嗎？」

這一次，她沒有搖頭。

她也沒有點頭，只在倒下時越過接觸孔，一把抓住他的左手腕。

力道大得幾乎不像受傷的人。她的指甲隔著防護袖壓進他皮膚，整條手臂因顫抖而僵硬。昭黎沒有反握，也沒有把她拉近，只讓手腕停在原處，另一手托住接觸孔邊緣，避免她的肩膀承受全部重量。

「我不會拉你。」他說，「你可以自己鬆。」

白衣醫療艇員從側邊靠近，女人立即發出短促的聲音，抓得更緊。

「停。」昭黎說。

艇員停下。「她的腕部在出血，需要處置。」

「先問。」

艇員蹲到她看得見的位置，把止血布、清洗液與剪刀一件件舉起來。每舉一件便說用途，再問能不能碰。女人對剪刀搖頭，對清洗液也搖頭；止血布問到第三次，她才點了一下，但仍不讓白衣袖口靠近。

「要他拿？」艇員指向昭黎。

女人的手指在昭黎腕上收了一下。

昭黎把那當成可能的選擇，不替她說成同意。「如果要我拿，請再點頭。」

她抬起臉，明確點頭。

醫療艇員把止血布放在接觸孔外，手完全離開後，昭黎才拿起。他又問一次能不能碰左腕。女人沒有鬆開他的左手，只把流血的那隻手向前送了半掌。

他用右手壓住止血布，力道依彌菈在頻道裡報的程度逐次增加。女人痛得肩膀發顫，卻沒有把手抽回。當彌菈問能否固定兩圈，她搖頭；昭黎便只維持按壓，不多做一步。

他不知道她為什麼只肯讓自己靠近。也許因為醒來時先聽見的是他的聲音，也許因為他把刀放遠，也可能只是白色防護衣令她想起某個無法說明的地方。任何理由都不能被他提前寫成信任。他只知道她每一次搖頭都清楚，而清楚的拒絕比他想要的答案更有用。

歸潮灣中層棧橋靠近時，透明甬道兩側已站滿人。瀾國港警、公議署封印員、五國觀測代表與醫療組隔著各自顏色的線等待。女人一看見那麼多面孔，手又抓緊。

晏泠站在最外側的藍線後。她公服的袖扣一高一低，右邊那枚扣進了錯的孔；手裡的記錄筆換過一支，原本那支躺在她腳邊，筆尖已摔裂。昭黎從沒見過她讓工具留在地上。

她看著罩內女人抓住他的手，目光停得比任何一次事故觀察都久。

「醫療轉運可否由其他救難員接手？」她問。

彌菈在頻道裡回答：「病患拒絕。」

「她尚未完成身分與意識評估，指定接觸者的效力需要——」

「她能逐項理解、拒絕並改變答案。這已足以使『不要別人碰』現在有效。」

晏泠的下顎繃緊。她彎腰撿筆時，第一次沒有一次握準，指尖撞了兩下石面才把筆抓起。站直後，她把右袖扣重新扣好，聲音恢復平穩：「記錄病患暫時指定昭黎為可接近救援者。此指定不擴張為詢問、採樣或永久代理權。」

昭黎看見她在說「昭黎」兩字前停了一瞬。

棧橋人員推來低床。白衣艇員先詢問女人是否願意移動，她搖頭；詢問是否能讓低床靠近，她看了很久，點頭；問能不能割開黏住傷口的袖子，她再次搖頭。每一個拒絕都使流程慢下來，卻沒有人因此跨過她的手。

昭黎隨低床走進透明甬道。按照接觸程序，他的救難服、引航牌與所有工具都被視為證物；按照醫療界線，他不能替女人回答姓名與來處。他唯一能做的只是讓手腕留在她抓得到的位置，並在每一道門前說明下一步。

過了第一道清洗閘，她終於開口：「賽芙拉。」

那聲音很輕，卻使滿走廊的職稱與編號忽然退開一步。她先交出的不是船，也不是航線，而是仍屬於自己的名字。

昭黎低頭看她。「這是你的名字？」

她點頭。

「我叫昭黎。」

賽芙拉的眼神落到他胸前被封袋罩住的名牌，像早已看過。她的嘴唇動了動，沒有重複他的名字，也沒有道謝。

第二道門準備關閉時，彌菈問她是否願意讓昭黎在醫療艙外等待。賽芙拉先看出口，再看兩側的人，最後仍沒有鬆手。

昭黎的腕骨已被抓得發麻。他可以依法要求替換；她抓住他也不代表他從此欠她陪伴。但當下每一個可替換的人都被拒絕，而她唯一肯接受的止血布仍壓在他右手下。

「我先把止血與轉運交接完成。」他說，「交接後如果醫官准許，我會自己決定留下；你也隨時可以叫我走。」

賽芙拉閉上眼，手指卻沒有放鬆。

隔離門在他身後落鎖。透過逐漸變霧的玻璃，他看見晏泠站在藍線外，把那支摔裂的筆收進證物袋，親自補寫方才兩次更正。她沒有再要求換人，也沒有離開。

昭黎原本只是救援主舵者；門關上後，他成了唯一已知倖存者當下指定願意接近的人。那隻不肯鬆開的手沒有許諾信任，更沒有許諾將來；而他在依法可以要求替換時，仍主動選擇先完成醫療交接，再承擔自己留下或離開的決定。
