# 最後一盞燈之外

遠溟三號越過最後一盞護航燈時，賽芙拉先看見門消失。

訊號席右側原本有一道通往外廊的窄門，門上掛著她自己檢查過的機械鎖；再往後是右尾維修梯，左前方則能越過船橋出去。她在解纜前已數過三次。護航燈由右舷退到船尾的那一息，窄門成了一面沒有縫的黑木，維修梯被舊主船的灰色艙壁取代，左前方只剩一扇向內開的白門。

她沒有碰白門。

「定向確認。」彌菈的聲音從醫療席傳來，「報姓名、位置與真實出口。」

「賽芙拉。遠溟三號訊號席。右側窄門、右後維修梯、左前船橋。」她看著三個都已不存在的方向，「視野被改寫，觸覺待確認。」

賽芙拉伸手去摸右側。掌心先碰到一片溫熱木板，指尖再往前半寸，卻摸到熟悉的冷金屬鎖舌。視野裡沒有門，真實的門仍在。

伊嵐立刻把所有席位由目視導航改成觸覺繩與被動儀表。「移動舟域偏差一成八，未過中止線。外部出現大尺度遮蔽，不能確認是生物、界壓形變或認知重疊。」

賽芙拉抬眼。

最後一盞燈外沒有浪。

海面像一整片向下凹陷的黑鏡，遠溟三號與九個移動舟點沿鏡面邊緣滑行。更遠處，一道巨大的影子從海平線以下升起。它沒有固定頭顱，也沒有能數清的肢體；每一次船燈熄亮，影子便換成不同輪廓，有時像一艘把天空當帆的船，有時像背朝他們伏在海上的人，有時只是一堵比雲更黑、表面緩慢張開無數白點的牆。

白點不是眼睛。至少沒有人能證明。

它們只是同時朝向遠溟三號。

共同牆將名稱留空。晦岑的歷史席只送來一句：「舊誌稱看潮者、負岸者與無面船，彼此不一致。不要把任何一個名字當本質。」

船橋暫用「觀潮巨影」標示可觀察對象，不寫生物。

主船訊號從巨影裡傳來。

一短、兩長、四聲船鐘，半個人名。這次後面多了三段只有賽芙拉熟悉的值班縮語：左七未沉，伴航三保留空氣，主甲板有十一人能回答。

她的手抓住桌沿。

左七是她失聯前最後一次換班的艙段。伴航三的艇長總把「保留空氣」說成「還有一口」，嫌正式用語太像遺言。主甲板十一人則是她親眼點過的數目；那一刻沒有岸上人、沒有昭黎，也沒有遠溟三號的事故記錄能知道。

「新增內容。」她說，喉嚨發緊，「包含未公開值班縮語與人數。仍不能證明來源。」

盲核員只聽見船鐘，聽不見後三段。

「私人指向成立。」另一名訊號員回報，「共同接收只有前段。建議不以後段導航。」

白門自行打開。

門後是主船走廊。沒有白痕，沒有乾裂遺體，艙燈用遠航前的黃色油罩，一名左七值班員站在走廊盡頭。她比賽芙拉記憶裡老了一點，右眉仍缺一角，手裡拿著那塊總被她偷去墊杯子的航跡板。

「妳終於來了。」值班員說，「主船在南七分。只要遠溟三號離開移動舟域，跟著我。」

昭黎出現在她身旁。

不是船橋上正在握舵的昭黎。這個昭黎沒有右手舊傷，肩上沒有三個女人留下過的任何痕跡。他把船長牌交到她手裡，說：「不用再盲核。妳給我的每一段，我都只信妳。」

那是她曾經想要的答案。

不是一句空泛的愛，而是把覆核撤掉，把上一次隱瞞造成的裂口從航誌裡撕掉，讓她重新成為唯一能告訴昭黎海往哪裡去的人。白門後有主船十一名生還者；身旁有一個不再要求別人校驗她的昭黎。晏泠留在燈內，彌菈也不會以醫療叫停。只有她、昭黎與她失去的人。

「賽芙拉，回報。」真實的昭黎從舵台叫她。

她看不見他，只看見幻象把船長牌按進自己掌心。

「我看見主船內廊。」賽芙拉說，「有左七值班員，也有你。它要我解除盲核、離開移動舟域，向南七分。」

「妳是否主張執行？」

幻象裡的值班員朝她伸手。「再慢一段，我們就只剩名字。」

賽芙拉想到白崖第三層那張朝出口的空床，想到北灣尾盤下沒有姓名的水手，想到自己曾把害怕被留下變成全船不知道的第三段。眼前主船細節比任何一次誘導都真；真到她不能用「一定是假的」讓選擇變得容易。

「我主張保留觀測，不主張執行。」她說。

她解開南七分舵標。

舵標不是一個象徵。它連著遠溟三號下一段航線生成器；只要賽芙拉把它壓入槽裡，伊嵐的模型便會把主船方位列作有效目標。她握住那枚溫熱金屬，拔出，放進三方封存盒，讓自己的手離開唯一能把幻象變成命令的位置。

白門後的值班員臉色變了。「妳又要留下我們。」

「可能。」賽芙拉回答。她沒有說你們都是假的，「但我不會替全船把可能生還寫成已同意。也不會用昭黎只信我，換你們的方向。」

幻象裡的昭黎說：「這就是妳的幸福。妳找到主船，也終於不必和任何人分我。」

賽芙拉把封存盒推給盲核員。「你不能替我選擇幸福。」

她這句話對著一張昭黎的臉說，也對著主船的門說。幸福若必須先刪掉晏泠、彌菈、覆核、責任與其他船員的退出權，便只是觀潮巨影替她整理好的牢房。門看似向外，其實只有一條路。

白門劇烈搖晃。真實訊號席右門的冷金屬重新出現在視野裡，主船走廊卻沒有完全消失，仍和外廊疊在一起。

「情報席主動拒絕私人方位。」盲核員把動作寫進共同紀錄，「南七分舵標已封存。」

另一側忽然傳來岸上航務指令。

晏泠的聲音比平日更近：「潮生港西口開放。遠溟三號可單船回港，其他舟點留在護航線外。」

賽芙拉看向共同牆。西口實況顯示仍是只出不進，潮生港三區疏散也沒有結束；那道指令卻帶著晏泠現職末次權限的真印，甚至附了第二事故官共同簽名。

「來源不一致。」伊嵐說，「數位印是真的，發令節點不存在。」

晏泠本人在公共線裡沒有回答。

畫面切到岸上席時，她站在一條乾燥棧橋。昭黎也站在她身旁，兩人面前是只容一艘船通過的西口。賽芙拉無法看見晏泠所見，只能看見她的手握住一張靠港指令，指節發白。

「晏泠，報妳看見的內容。」第二事故官要求。

她沒有立刻說。那兩息裡，遠溟三號的舵台真的收到靠港優先級；若昭黎接受，移動舟域會拆散，船能沿最短線回到燈內。

晏泠終於開口：「我看見西口只讓遠溟三號進港。昭黎在岸上等我，沒有其他伴侶，也沒有疏散船。指令說只要我以末次官權核准，我和他可以回到兩年前沒有分開的位置。」

她把內容說給全船聽，沒有用「與私人關係相關」遮掉最難看的部分。

「妳是否核准？」

晏泠將靠港指令從讀取槽抽出。她先把真印影像送入偽造證物欄，再用自己的離任識別牌撤銷本席轉送權。那個動作一生效，即使下一息出現真的緊急靠港，她也不能把昭黎排進審批線。

「不核准。」她說，「西口仍依全港疏散條件運作。我撤回只讓我與昭黎靠港的幻象指令，也撤回自己對本船的轉送權。若他回港，由其他席決定。」

畫面裡的乾燥棧橋從她腳下斷開。賽芙拉看見晏泠扶住真實東塔桌沿，右手仍在發抖；靠港優先級則從遠溟三號舵台消失。

晏泠沒有為她們作選擇。她只親手關掉那條只剩自己與昭黎的路。

觀潮巨影的輪廓又變了一次。

它伏低到海面，無數白點沿船群逐一亮起。每一艘舟點都開始報不同幻象：南泊浮標艇看見滿載未曾發現的外洋礦物；承國壓載駁看見一條不需瀾國港口的內海；朔庭界域艇看見失敗舟域武器完整展開；有人看見死去的家人，有人只看見自己安全返航。人人看見一條剛好證明自己原先選擇正確的航線。

遠溟三號的醫療牆同時轉綠。

所有船員生命值都顯示正常，白痕升溫歸零，耳壓錯置消失。只有昭黎的欄位在持續下降，旁邊跳出一項從未設過的醫療答案：切斷其他生命線，把全部界壓供應集中於船長一人；全船其餘席撤離，即可保全昭黎。

賽芙拉從訊號席看見彌菈讀完。

「這不是我們的醫療介面。」第二醫官說，「卻使用了真實基線和彌菈的個人簽章。」

昭黎的生命線又掉了一格。彌菈的手已放到集中供應控制柄上；只要向右扳，輪機與界域便會把剩餘穩定量優先送到舵台，其他人退到無保護狀態。

「彌菈。」昭黎說，「不要因為是我就——」

「你閉嘴。」她的聲音冷得像在急救線上，「現在你不是醫療判斷者。」

賽芙拉胸口一緊。那句話可能表示彌菈要救他，也可能表示她正在拒絕讓昭黎用犧牲自己替所有人回答。

彌菈先請第二醫官讀實際脈搏。對方回報昭黎與全船基線都有波動，但沒有任何一人達到單獨供應條件；綠色牆面是虛假整齊，原始貼片仍顯示十二條不同曲線。

「我看見的答案是只保全昭黎。」彌菈公開說，「它要我把其他生命線切掉，讓船上只剩他與我。那不是醫療中止，是用我的權力替別人選擇死亡。」

她把集中供應控制柄的安全銷整枚拔出，交給第二醫官保管，再將全船供應改為各席原始配額。這使她不能單獨扳向昭黎，也沒有取消真正緊急時逐項調整的醫療權。

「拒絕虛假醫療答案。」彌菈說，「昭黎沒有優先於其他船員。我的中止仍有效，但不為只留下他服務。」

昭黎的生命欄恢復成真實值。並不漂亮：右手震感偏高，心率超出基線一成六，仍在事前可行線內。彌菈沒有因幻象退去就說他沒事，只命第二操作者增加覆核頻率。

賽芙拉看見三個動作都留在船的可觀察記錄裡。

她拔掉南七分舵標；晏泠撤回只讓一艘船靠港的幻象指令與自己的轉送權；彌菈拔掉集中供應安全銷，拒絕只保全昭黎。沒有誰只在心裡戰勝佔有，也沒有誰以一句理解排他幻境便自動安全。三個人都親手讓自己最想要的路失去執行能力。

昭黎沒有把她們的拒絕說成愛的證明。

「情報、航務、醫療中止均已觸發私人指向。」他說，「依共同航線，第二段終點到達，停止生成下一段。各舟點原位被動觀測，退出角保持。」

他真的停了。

沒有趁三人剛拒絕幻象便要求多走一段，也沒有說既然彼此坦白，核心就會給出答案。遠溟三號降到最低船速，移動舟域的各點也停止形成完整圖形，只保持能各自離開的距離。

觀潮巨影沒有因被拒絕而消失。

它反而更近。黑色輪廓越過南泊最外一艘浮標艇，卻沒有在實際海面留下排水；白點沿所有船員曾走過的航線連成圖，三座熄滅的錨、白崖內弧、北灣無旗艦進港線與潮生港西口同時浮在天空。每一條都是真的歷史位置，組合起來卻指向遠溟三號此刻不在的地方。

伊嵐說：「它正在用我們的記憶和歷史航圖重建座標。幻象不是目的，是讓我們主動選一條可重複的真路。」

「能切斷嗎？」昭黎問。

「不知道。固定停著只會讓它取得更多交點。」

晦岑的歷史席回報，三座熄滅錨的海床舊構造仍在被讀取。剩下兩座雖轉被動，也開始出現與巨影白點同步的微弱回壓。潮生港已不能只靠熄燈藏住位置。

賽芙拉望著仍半開的白門。

主船值班員站在門後，不再叫她。十一個生命訊號沿走廊一明一滅，其中一個舉起她曾用過的舵標，像在等待她改變主意。賽芙拉不能證明那些人不存在，也不能證明拒絕方位沒有親手錯過他們。

她把這項不知道說出口。

「我仍想去南七分。」她說，「仍想要主船是真的，也仍想要昭黎只信我。但這些都不能成為全船下一段的唯一依據。」

晏泠在線路另一端說：「我仍想讓他回到只有我能開的港。」

彌菈說：「我仍想在能選時先保住他。」

三句話沒有互相安慰。

賽芙拉甚至因另外兩人的欲望仍在而感到刺痛。她不喜歡晏泠把「回來」說得像一段兩人共有的歷史，也不喜歡彌菈能碰那個集中供應柄。拒絕排他幻境不等於她願意把佔有平均分配，更不等於三個人從此和諧。

可她已看見另外兩人都沒有替她把路關掉。晏泠撤的是自己的優先靠港，不是賽芙拉的主船目標；彌菈拒絕的是只救昭黎，不是用醫療禁止賽芙拉繼續判讀。

「下一段需要新的物理解法。」伊嵐說，「不是更誠實的願望。」

昭黎將舵交給韓澤，自己離開主操作者位置去看船體實值。受損左板使遠溟三號不能照巨影投出的直線轉向，右尾隔片又在最低速時鬆了一線；這些缺陷此刻反而是少數沒有被幻象整理成完美答案的東西。

賽芙拉摸到真實右門的鎖舌。她沒有開，也沒有把門封死，只確認出口仍在。

最後一盞燈已落到身後。岸上最強的界域、巡防炮與固定錨都不能在這裡替他們決定下一步。觀潮巨影懸在前方，把人人想要的航線鋪成一片過分明亮的海。

遠溟三號沒有選其中任何一條。

它停在所有答案之外，帶著未修的裂縫、仍需覆核的訊號與三次主動拒絕，等待全船提出一個不靠誰獨占幸福也能成立的方法。
