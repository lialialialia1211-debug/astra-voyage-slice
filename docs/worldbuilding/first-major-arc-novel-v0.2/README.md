## 本章功能性名詞

- **拍賣燈：**南泊商船用於競價泊位的人工舉燈工具；因各船手動、無固定順序，終局用來把移動舟域的相位承受權逐搏交給不同舟點。這是本章現場既有工具，不擴張為新的世界級技術體系。
- **空鐘礁：**第一張限制深海航照指定的北弧終點與外側觀測點；功能是給第一航次一個可停止、可返航、遠離南七分未知訊號的許可邊界。本章不追加其歷史、居民或上層祕密。
