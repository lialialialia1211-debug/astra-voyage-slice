# 第 23 幕　三種救他的方式

午潮前四刻，晏泠說要攔船。

「不是奪船。」她把北灣港務條文攤在租來的倉桌上，「只要證明移交會破壞仍在保全中的事故原物，朔庭船塢長有權拒絕解纜，直到獨立席覆核接收令。」

同一張桌的另一端，賽芙拉說要奪船。

「接收艇的船尾吃水太淺，拖不動遠溟三號。」她用指尖壓住維修通道圖，「他們會先讓五名自己的輪機員上船。那時右尾內廊只剩一人看守。我進去解開船塢供能，莫棠讓右中閥回位，昭黎從外側水梯上船。半刻以前就能離港。」

彌菈沒有把第三張圖放上桌。

「兩個都停止。」她說。

晏泠抬眼。「我的方案沒有讓他登船。」

「你的申請需要昭黎以船況見證者身分重做一次核心不認人的現場測試。資產接收席已拒絕書面疊圖，會要求他在核心旁完成接近、離開與壓力刺激。那是在用他的生命與身體證明你愛的人不是一把鑰匙。」

「測試可以設停止線。」

「他已停職，日常醫療剛轉交，左外板與右尾都未完成海試。對方若把壓力推到核心反應線，再叫他多留一輪，你能用什麼權力關掉？」

晏泠的手指停在條文上。她沒有案件權，沒有醫療權，也沒有船塢控制權。她能提出條文，不能親手停測。

賽芙拉說：「所以直接走。」

彌菈轉向她。「你的方案把昭黎放到一艘船況未知、出港即遭軍警追截的船上。你知道右尾失效條件，也知道他不會在船員沒回答時離港。」

「那就不要讓他知道全部。」

桌邊的空氣一下變冷。

賽芙拉沒有收回。她已經因隱瞞第三段訊號失去單獨處理主船訊號的權限，也知道那句話會碰到哪道尚未修好的裂口。她仍把它說出來，像寧可讓所有人看見自己又想抓住什麼，也不肯把動機藏回安全理由。

昭黎坐在靠牆的一張低椅上。他沒有船況牌，沒有舵令板，連右手復健都已由遲越接管。三個女人在他面前爭論如何救他，卻沒有一個方案先問他願意承擔什麼。

這景象本來應該使他感到被需要。

實際上，他只看見三種熟悉的錯誤。

晏泠相信程序只要找到正確的縫，就能讓所有傷害暫停；賽芙拉相信門若即將關上，先離開的人才保有名字；彌菈則站在兩條路中間，用不讓他冒險證明自己仍能守住最後一條線。

她們都想救他。

也都正在把自己的恐懼說成唯一可行的辦法。

「先停。」昭黎說。

沒有人聽。

晏泠正指出船塢長拒絕解纜需要可具名證詞；賽芙拉說封印官已被接收席換成外來人，合法見證會在午潮前失效；彌菈要求任何方案先排除昭黎直接接觸核心。每個人的話都有證據，每個人也都在別人句子未完以前找到反對。

昭黎站起來，把桌上唯一一盞油燈熄掉。

倉房暗下來，三個聲音同時停住。門縫仍有日光，所有人都能看見出口，卻看不清彼此手上的圖。

「我不要求妳們先相處得好。」昭黎說，「也不要求任何人退成不在意。現在一人一次，只回答能承擔什麼，不能替別人承擔什麼。」

晏泠第一個皺眉。「這不是表決。」

「對。表決也不能替船員同意風險。我要的是方案界線。」

他重新點燈，把三張空白紙分開放。沒有平均位置，也沒有誰先說便比較重要。

「晏泠。」

她看著他，像仍不習慣他在沒有職稱時直叫名字。

「我能以一般證人與民用航務申請人的身分，整理公開船塢法、提交原始資格通知，並找到有權拒絕不安全解纜的人。」她說，「我不能開你的案卷、不能命令扣船、不能要求航照或船權結果，也不能保證申請在午潮前被受理。」

「妳能承擔什麼後果？」

「如果攔船失敗，我的名字會在一份被認定為替伴侶濫用一般申訴的紀錄上。未來申請民用航務職時，對方可以用它質疑我的合規判斷。」

她說完，沒有補一句仍值得。

昭黎把原話記下，轉向賽芙拉。

「我能進右尾，能讓接收員在不破壞船體的情況下找不到主隔離扣，也能帶願意的人從水梯上船。」她說，「我不能保證出港後不被擊沉，不能替任何船員同意，也不能讓遠溟三號在目前船損下全速走。」

「後果？」

「若直接奪船，我會成為違反停泊令的人。主船情報控制、離船權與艙室都不能阻止港警拘捕。」

「妳願意承擔拘捕，不等於別人願意。」

「我知道。」她停了一息，「但我仍想這樣做。」

昭黎也記下。最後看向彌菈。

她沒有坐。醫療轉交後，她像失去一個習慣站立的精確位置，雙手始終空著。

「我能以檢疫與全船安全席判斷，接收團的解列計畫是否會使船內殘留物、白痕風險與傷員暴露失控。我能要求他們先提出撤離、污染與緊急救援方案。」她說，「我不能用你的私人狀態拖延，也不能因我怕你死，就把所有可能受傷的事都列為醫療禁止。」

「後果？」

「我已申報偏袒。若我再對你單獨下中止，任何人都會問是全船標準還是私人恐懼。我可能失去檢疫席的可信度。」

「還有呢？」

彌菈看向另外兩人。她們都知道昭黎和自己的關係，卻尚未聽她在非醫療記錄裡完整承認。

「我想要他。」她說。

晏泠的臉沒有變，右手卻摸上不存在的袖扣。賽芙拉則把椅腳轉向門，像那句話使出口忽然更重要。

彌菈沒有退回職責後面。「我不想用他冒險的程度證明他選誰，也不想讓他用自己的生命證明對任何一個人的感情。你們的方案若把『昭黎願不願登船』變成愛的測驗，我會反對。」

晏泠冷聲問：「你昨日才轉交他的日常醫療，就在這裡宣告想要他？」

「轉交不是為了取得他，是因我已經不適任繼續掌握那部分權力。」

「你早就想要。」

「是。」

「那你以前對我的利益衝突質問，有多少是嫉妒？」

「一部分。」彌菈說，「你的舊情確實影響程序，也是事實。兩件事一起存在。」

晏泠的眼神更冷。她最清楚一句正確質疑如何同時帶著私心，因此沒有辦法只抓住其中一面否定。

賽芙拉問：「妳看過我的病歷，碰過我的身體。現在也要和他建立關係？」

「我曾是妳的醫官。妳的急性醫療與強制隔離都已解除，私人病歷仍由妳控制。我不會要求妳接受我，也不會以同處一段多伴侶關係取得妳的任何資訊。」

「那妳會不會叫他別碰我？」

「若沒有急性醫療理由，不會。嫉妒不構成中止條件。」

「妳會嫉妒？」

「會。」

賽芙拉看了她很久。「至少妳沒有說理解我們的文化，所以不會。」

那不是和解，只是一把暫時沒有再推深的刀。

晏泠轉向昭黎。「你呢？你能承擔什麼？」

昭黎看著三張紙。他最容易說的仍是全部。停職、拘捕、船損、她們彼此的怒意，全算在他身上。那句話曾使他覺得自己像一根能把船綁住的主纜，也曾讓四十七息裡來不及回答的人替他承受轉向。

「我能提交自己的申辯，接受停職，不登船作危險適配測試，也不要求妳們為了我違反各自職責。」他說，「我不能保證船留下，不能替船員選逃亡，也不能讓妳們先不嫉妒才合作。」

賽芙拉問：「如果合法方法失敗？」

「再問還有哪些人願意承擔新的選擇。不是先偷走答案。」

「到那時船已經離岸。」

「所以我們要讓合法方法不只靠一份申請。」

晏泠抬眼。昭黎把她的條文、賽芙拉的通道圖與彌菈的解列風險頁並排，卻沒有疊成一份由他發令的方案。

「移交需要三個實際節點，」他說，「船塢長解除岸纜與供能；封印官確認原船、證物和接收封條一致；現有船員完成離船與私人區清點。少一項，接收席只能取得紙上的船。」

晏泠立即接上。「船塢長可以因船體不安全拒絕解纜，但需要修復者具名證明。資產接收席現在只附自己的結構師報告。」

「莫棠、兩名北灣輪機員和尾盤實際修復者都能作證。」昭黎看向賽芙拉，「妳願不願把通道圖從奪船路線改成船損證詞？指出接收團沒有檢查的右尾隔片、卡閥與失效出口。」

賽芙拉的手壓在圖上。「那會把我的進船路徑交給船塢長。」

「只交影響安全的段落。私人避讓通道可以遮掉。」

「你仍可能失去船。」

「是。」

她沒有立刻同意。

彌菈說：「封印官的部分，偽造文件不是唯一缺口。接收令把賽芙拉的獨立艙房列作待清點私人區，卻沒有她本人撤回控制；也沒有白崖資料、尾盤封存與病歷污染物的分流計畫。封印內容和實船不一致，我可以拒絕醫療與檢疫證物交接。」

「妳不能拒絕船權移交。」晏泠說。

「不能。但封印官若在有未交接證物時宣告整船一致，他本人要負偽證責任。」

晏泠把條文翻到證物交接附則。「所以我們不請他幫昭黎。我們請他為自己的印作證。」

昭黎點頭。「第三項是船員。」

賽芙拉立刻說：「讓他們拒絕離船。」

「不能用拒絕服從接收命令當唯一方法。」晏泠說，「但每個人的工作紀錄、私人艙物與尚未完成的安全交接都能形成具名證詞。接收席若跳過，移交不是完成，只是把人趕下船。」

「誰去問？」彌菈問。

「不是昭黎。」晏泠說，「他仍被指控預先操控船員。由船塢工會見證，每個人分開回答：願不願在目前船況下把自己已知的安全責任交給接收團；哪些項目尚未完成；是否受到昭黎或任何一方威脅。」

方案第一次不需要昭黎用身體碰核心，也不需要賽芙拉先把船開出港。

它需要船塢長、封印官與船員三種互不代替的證詞。晏泠提供法律攔船路徑，賽芙拉用自己知道的船內缺口證明接收報告不實，彌菈把醫療、檢疫與私人資料從整船資產中拆出。每一項都能被其中一人叫停，也沒有哪一個人的愛成為授權。

「若三項都成立，」晏泠說，「朔庭北灣可依本港安全權暫停解纜，第二事故官取得時間查密印。不是把船判給你，只是拒絕讓一份有重大不一致的接收令先完成事實。」

「若只成立兩項？」昭黎問。

「船仍可能被帶走。」

「若接收席強行登船？」

賽芙拉把通道圖往桌中央推了一半。「我可以帶封印官和船塢見證者從右尾上船，讓他們親眼看。不是帶昭黎，也不啟動船。」

「妳的中止點？」昭黎問。

「任何接收員持武器進私人艙、要求我交主船內容，或阻止我離船，我退出見證。通道圖仍只公開安全段落。」

彌菈說：「登艦者若出現方向錯置、白痕反應或船體壓差越線，醫療席中止。這條對所有人一樣，包括賽芙拉。」

晏泠補上：「港務見證若被排除，我的合法攔船申請失去事實基礎，現場行動停止，改向第二事故官申請緊急保全。沒有人趁混亂解纜。」

三個停止點分別落在三張紙上。

昭黎問最後一題：「妳們願意讓方案裡保留另外兩人的權限，即使不相信她？」

晏泠先說：「我不相信賽芙拉會在主船訊號再次出現時立即交出全部。但這次她只負責可見通道與船損，封印官和輪機員同在。我接受。」

賽芙拉說：「我不相信晏泠的法律一定來得及，也不相信她不會在能選時先把我留岸。但她沒有單獨扣船權。我接受。」

彌菈說：「我不相信自己不會再偏袒昭黎。所以我的單獨中止須留下即時數值，能等時由遲越覆核。急性生命危險除外。我接受。」

她們沒有說信任彼此。

只說願意讓對方的停止點真實存在。

午潮前兩刻，第一批船員證詞開始。莫棠拄著胸側固定帶到工會桌前，逐項指出右中閥只能在三分內運作；接收團報告卻寫「壓載全功能」。尾盤修復者展示浮動隔片限制頁，證明半速以上未完成海試。右外甲板水手仍不公開姓名，只透過獨立見證說新護欄第六扣重鉚後尚未經實浪測試。

船塢長在三份證詞下簽了暫不解纜，不接受資產接收席以政治命令代替船況責任。

封印官的證詞更慢。賽芙拉帶他從右尾進船，彌菈在外側監看生命值，晏泠只能站在一般申請線等待。半刻後，封印官帶著一枚沒有列入接收清單的私人控制鎖出來——那是賽芙拉獨立艙房的門牌底座，仍刻著她的名字。

「整船資產清點不一致。」他說，「本人未撤回私人區，醫療與航安證物未分流。我拒絕在現有接收封印上落名。」

第三項船員證詞送達時，午潮只剩四十七息。

十九名現有修復、值勤與證物人員裡，十六人拒絕確認安全交接完成，兩人表示資料不足，一人願意移交但要求先完成右尾實浪測試。沒有人說願意跟昭黎逃亡，也沒有人替他宣誓。

他們只拒絕讓別人把尚未完成寫成完成。

資產接收席仍命拖艇啟動。岸纜卻掌握在朔庭船塢長手裡，封印官的接收欄空白，船員證詞同步進入第二事故席。晏泠提交緊急保全申請，簽名欄只寫一般證人與民用航務申請人，不再假裝自己仍有官權。

倒數到第十一息，第二事故官下令暫停移交。

不是把遠溟三號交還昭黎。命令只確認接收文件與實船狀態存在重大不一致，原封印不得執行；船留北灣，由朔庭船塢、六方證物席與現有船員共同保全，等待密印來源查驗。

賽芙拉看著拖艇熄火，手仍按在通道圖上。「如果沒有下令，我會開船。」

晏泠說：「我知道。」

「妳會攔我。」

「會。」

彌菈接著說：「如果昭黎上船，我也會中止。」

三個答案沒有讓任何人安心。

昭黎卻第一次覺得那艘船可能真的有一個不是靠他獨自抓住的未來。船塢長的纜、封印官空著的印、十九名船員各自留下的回答，以及三個女人互不信任仍願意保留的停止點，共同把遠溟三號留在岸邊。

他沒有握舵。

船也沒有認主。

午潮越過纜柱時，黑色船腹只依水位抬高半掌。第二顆心照壓載規律跳動，不知道桌邊三個人剛才都承認想要誰。

移交被攔下，偽造密印的來源仍未知。

下一步不再是三種彼此排斥的救法。它已被迫變成一條任何一處謊言都能叫停、任何一個人也不能單獨帶走的奪船路徑。
