# 第 21 幕　被選中的假證據

偽造文件最像真的地方，是它沒有寫「天命」。

它寫的是適配率。

昭黎坐在北灣臨時事故室，看著自己十七歲時的手部震感測驗、十九歲時的救難壓力評估、加入折蘆後的三次水下方向辨認，被剪成一份從未做過的「深洋共生核心操作者人才序列」。每一個數字都曾屬於他，每一個欄名卻都不是原來的欄名。

震感測驗原本只判斷學員能否隔著船板分辨纜索拖底。文件把「每息五次規律振動」改成「可辨識核心第五搏」；救難壓力評估記的是他在翻覆艇內維持清醒的時間，到了新表上，成了「異常界壓耐受」；水下方向辨認更乾脆，原本三次裡有一次答錯，新文件只留下兩次正確值，旁邊補上一枚早於遠溟三號返航十一個月的中央密印。

結論寫得冷靜而完整：昭黎自十七歲起即列入秘密遠航返航接觸名單；遠溟三號核心將其辨識為優先操作者；四十七息改道並非臨場越權，而是預定接管程序的一部分。

若它成立，晏泠替他留下救援窗口、賽芙拉指定他接近、彌菈准他多次進入檢疫與船體區，便都能被拼成一套早已安排好的交接。港口獲救不再是一項需要同時保存功過的選擇，而成了「被選中者」照計畫取得黑船。

昭黎把紙翻回第一頁。「原件在哪裡？」

第二事故官坐在對面，沒有使用晏泠曾放在桌上的案件印。那枚印已交還，現在由另一名封印員保管。「提交者主張原件涉及五國秘密人才網，只交出六方同驗影本與密印雜湊。依現行證物規則，影本足以啟動保全，不足以作終局認定。」

「誰提交？」

「止潮公議署資產接收席，附中央航務總監辦公室轉介。兩方都說資料由匿名內部告發者提供。」

「所以仍不知道來源。」

「對。」

第二事故官把另一張紙推給他。那是停職與船體臨時移交令。昭黎原本只有一次近海查證的受監督操船權，白崖任務中止靠泊後便已失效；如今連後續資格申請、船況見證與修復協調都被停止。遠溟三號將在明日午潮移交公議署資產接收席，再由五國指定保管團送往解列船塢。

「解列？」昭黎問。

「文件用詞是分離高風險共生構造、保全船體。」

「先前共同實驗已證明，發光結構參與龍骨、壓載與舵機受力，不能當成一件能安全拆走的東西。」

「那份證據仍有效。但新文件主張，你當時讓核心呈現依附反應，因此『不能拆』可能只是被選中者阻止移交的說法。」

昭黎看向窗外。

遠溟三號泊在北灣內渠，左外艙封板仍比右側低一線，右尾新護欄只有六處換成合格備扣。尾盤的浮動隔片通過干擾台，尚未經海上受力；七枚進水晶片沒有修復，後部航誌架仍空著。那不是一艘藏著寶物、等某個人伸手取走的神船。它是一具受傷、被不同國家零件與許多人修補過的船身。

中央節點此刻在玻璃外穩定亮滅，沒有因昭黎被停職而變暗，也沒有朝他所在的事故室偏移半分。

「我要在回答前做一項公開確認。」昭黎說。

「你可以提出。」

「讓伊嵐把核心現在的受力、亮度與我進出船塢的時刻疊圖。從我到北灣至今全部都要，不只截出登艦時段。」

第二事故官記下。「用途？」

「反證特定操作者依附。若核心認我，它至少該在我離船、停權或接近時留下可重複差異。」

「若真的有差異？」

「照實留。」

這不是昭黎想要的答案。他曾經夢過自己的船，夢裡舵輪只在他掌下服從，所有人只要看見船如何回應便知道他有資格帶它出海。那種夢不必等待三國同意，不必讓醫療席叫停，也不必在每一次選擇後坐進沒有窗的審查廳。

此刻有人把那個夢做成證物送到他面前。

只要他說也許核心確實選了他，四十七息便能從未完成同意改寫成天命比程序更早抵達。他甚至可能暫時保住船。代價只是承認其他人的停止權、傷勢與反對，全是某段命定道路旁的雜音。

昭黎拿起停職令，在已知欄簽名。

「我依法停職。」他說，「也申請保全全部原始人才評估、測驗器材版本、密印簽發紀錄與影本產生路徑。我不主張核心選中我，不以這份文件要求繼續接觸船。」

第二事故官問：「你知道簽下後，午潮移交仍會執行？」

「知道。」

「也知道你不能登船自行證明？」

「知道。」

他把筆放回桌上，沒有抓緊。

事故室外等著三個人。

晏泠站在一般證人線後，深色便服的腰側沒有案件印。她看見停職令上的簽名，第一個動作是朝原本放讀取牌的位置摸去，手抬到一半才停。迴避仍在，她不能開原件，不能要求扣船，也不能把昭黎排進較安全的詢問順序。

「我可以提交折蘆舊訓練表的私人留存。」她說，「但只能走一般證人程序。」

「別用沒有合法來源的副本。」昭黎說。

晏泠的眼神冷下來。「你以為我會為了你再造一份？」

「我知道妳不會。我是說，只交妳當年依法接觸過、現在仍有權持有的部分。」

「這句不必你教。」她的語氣仍尖，卻把原本已打開的私人舊檔頁關掉一層，「我有你十九歲資格覆核時寄給受訓者本人的結果通知，能證明欄名原是救難壓力，不是界壓適配。提交後由獨立席判斷。」

她能做的只有那麼多。昭黎看得出那使她比任何公開質疑都更疼。從前她會用一枚印把門留到第十三息；如今即使他將被帶離遠溟三號，她也只能站在線外遞一份普通證詞。

賽芙拉不站在線後。

她靠近外廊出口，手裡握著遠溟三號右尾維修通道圖。那張圖由她親手補全，知道哪一段艙壁在低潮會離監看鏡半臂，哪一枚舊鎖不必主動訊號便能從裡面開。

「午潮前有一段換班空隙。」她說，「公議署接收人員不認得尾盤隔片。只要三個人進去，船能離泊。」

第二事故官還沒走遠。這句話足以成為奪船意圖，卻不是含糊威脅。

昭黎問：「離泊以後呢？」

「向北。沒有固定錨的地方。」

「右尾受損，左板只能半速，海上隔片沒有驗。出港警戒線後會被當成無籍船。」

「至少不會被拆。」

「船員願不願意？」

賽芙拉的下顎收緊。「可以在船上問。」

「不行。」

那兩字使她望向昭黎，眼神像白崖外的黑浪忽然合攏。

「你寧可他們把船帶走？」

「不。」昭黎說，「但我不會再把來不及回答的人帶離港，然後說責任算我的。妳的路線可以保船，也會讓船上每個人替我們成為逃犯。」

「他們正在用假文件合法地奪走它。」

「所以要拆的是合法外表，不是直接把船開走。」

賽芙拉把通道圖折回去，沒有撕掉。「你沒有操船權。」

「我知道。」

「晏泠也沒有案權。」

「我知道。」

「那你剩下什麼？」

昭黎看著她。七日前，她曾因害怕失去最後價值，把第三段訊號藏進腕骨；現在那道信任裂口仍在。她交出訊號、修好隔片並選擇留下，都沒有讓他能用一句相信免去覆核。她提出直接奪船，既因那是她熟悉的生存方式，也因她確實不相信岸上程序會在午潮前救下遠溟三號。

「申辯權。」昭黎說，「還有不是由我一個人持有的原始紀錄。」

賽芙拉沒有被說服。她只把通道圖收進自己的衣袋，沒有交給他。

彌菈最後才走近。

她從事故室開門起便沒有先看偽造文件，而是在看昭黎：呼吸、站姿、右手是否反覆碰掌根。他不是她的住院病患，卻仍由她負責日常傷後覆核；她只要說他在壓力下出現方向錯置，就能用醫療中止把移交程序拖過午潮。

昭黎看見她拿出三欄記錄片，第一欄已寫下兩項事實：右手舊傷無新增惡化；定向回答完整。第二欄「可能因壓力升高而不適任詢問」被劃去，第三欄本人原話仍空著。

「妳想問什麼？」他說。

「你現在是否想傷害自己、用登船或接觸核心證明文件錯誤？」

「不想。」

「是否能接受今天不登船？」

昭黎望向玻璃外的黑船。「能接受。不是願意失去它。」

彌菈把原話寫下。她的筆很穩，握得卻比平日更緊。

「我可以作成不適任。」她說得很低，只讓他們三人聽見，「你的白崖事故後疲勞、舊傷與今日壓力，足以支持保守觀察。那會延後問訊與移交接觸。」

晏泠立刻看向她。「是否符合你對其他同狀態者的標準？」

彌菈沒有回答。

那段沉默比承認更快。

昭黎胸口一沉。他曾把彌菈視作全船最能把事實、推測與需要分開的人。此刻她眼底卻有一種他從未被允許細看的恐懼，不是怕港口、怕污染，也不是怕偽造文件成立。

他只能從她握筆的力道判讀：她怕他被帶走。

「不要。」昭黎說。

彌菈的嘴唇抿成直線。「我還沒作成。」

「所以現在停。」

「你沒有醫療命令權。」

「我在回答妳剛才沒問出口的事。我不要妳把害怕寫成我的症狀。」

她的臉色微微變白。晏泠站在線外，賽芙拉握著能偷走船的通道圖，沒有人替彌菈把那句話說得比較好聽。

彌菈低頭，在第二欄寫：本人目前未達失能標準；醫官產生以保守分類延遲移交之傾向，私人因素待申報。

「我會處理。」她說。

「處理什麼？」晏泠問。

「我對他的醫療權。」

昭黎想追問，彌菈已把記錄片封入個人醫療稽核槽。她沒有用尚未生效的決定換他的安慰，也沒有讓他碰她。

午潮移交倒數在外牆亮起。

資產接收席派來的人開始丈量登艦橋，將原本寫著賽芙拉姓名的獨立艙房改列「待清點私人區」。她站在玻璃後看見，手指再次摸向衣袋裡的通道圖。晏泠則坐到一般證人桌，從自己十九歲時收到的資格通知一頁頁建立合法來源。彌菈走向另一間醫療通信室，門關上前，先把昭黎今日的日常覆核頁送給一名他沒見過的北灣醫官。

三個女人各自選了一條路。

一條只有法律允許的窄縫，一條能在夜裡直接把船開走，一條則必須先承認自己已不適合站在原來的位置。

昭黎被要求交回最後一枚船況見證牌。封印員把它掛進移交箱時，遠溟三號中央節點依船塢供能下降而暗了一階；昭黎退後，它沒有跟隨。接收席代表走近，它也沒有亮起。

「你們仍可以說它認我。」昭黎對第二事故官道，「但先把供能曲線放在旁邊。」

伊嵐的第一批疊圖在此時送達。核心亮度與壓載、船塢供能及左外板受力高度相關；昭黎進出船塢四十一次，沒有任何可重複的人員接近反應。文件所稱「優先操作者脈衝」出現過九次，其中三次昭黎在潮生港、兩次昏睡、一次尚未登上遠溟三號，其餘三次則分別對應抽水泵啟動、右中閥回位與第五搏補償。

折蘆舊訓練所的教官也在暮鐘前接上公開線。老人沒有說記得昭黎天賦異稟，只把十九歲那次測驗的缺點一項項念出：他能從混亂纜振裡找出不規律敲擊，卻在聽見有人落水的模擬喊聲後，連續兩次漏報右側張力；他的評語不是適合與未知核心共生，而是「現場感覺敏銳，會因急於救援縮短覆核，須由第二人確認」。

偽造文件保留了敏銳，刪掉了必須由別人確認。

教官出示當年器材領用簿。五塊測振板裡有一塊邊角破裂，昭黎的原始記錄特別註明第三輪改用備板；假文件上的三輪波形卻共享同一枚完整板號，連破板造成的雜訊都被修成平滑曲線。要做到這一步，造假者不只看過公開成績，還接觸過訓練所保存的細部副本，卻沒有拿到器材庫的紙本更換頁。

「我可以證明他接受普通救難評估，也可以證明這三條曲線不是當年存下的原貌。」教官說，「不能證明誰改。更不能因他後來真的摸過黑船，就把我十九歲時敲的一塊木板說成預言。」

昭黎向他道謝以前先問，這份證詞是否會使訓練所的學員資料被整批調取。教官已把範圍限在同器材、同日與昭黎本人授權頁，其他學員只以匿名板號交叉驗證。沒有人需要為拆穿一名假的被選中者，再把整班年輕人的身體與錯誤交出去。

證詞送入爭議卷後，資產接收席第一次撤回「秘密培訓無反證」這句話，改稱仍需等待中央密印來源。移交倒數沒有停止，理由卻又少了一根支柱。

這不足以立刻撤銷移交。影本仍帶著真密印，人才評估原始表也尚未全部調到。

卻足以證明核心沒有在玻璃後等它的主人。

第二事故官將疊圖納入公開爭議，命接收席不得以「核心服從昭黎」作為強制解列的單一理由。移交仍在倒數，措辭卻第一次改變：不是從被選中者手裡收回國家資產，而是一艘船權未定、證物來源可疑且結構不能安全分離的無籍返航船。

昭黎失去正式操船權，也失去站在修復架旁的資格。他沒有得到天命替自己穿過停職線。

暮色落下時，他在遠溟三號外最後摸了一次公共繫纜。繩結不是他綁的，仍牢牢扣著船與岸。隔著水面，第二顆心依壓載規律跳動，不知道誰愛他，也不替任何人作證。

午潮以前，他們必須找到另一種把船留下的方法。
