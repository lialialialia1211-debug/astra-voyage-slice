## 0. 本輪目標與修改門檻

本輪工作的主要目標，是補全世界觀中會直接支撐第一大章及遊戲視覺設計的部分。

優先順序為：

1. 統一篇幅層級與敘事名詞。
2. 確立第一大章的終點與八階段起承轉合。
3. 確立深洋物理封界、個人武力與船艦航行的共同規則。
4. 確立諸國對深洋的不同認知、既有手段與利益方向。
5. 確立返航事件、舟域核心及昭黎取得船與許可的政治合理性。
6. 先完成世界物理結構圖，再完成五國共域圖與第一大章地區圖。
7. 地圖、規則與人物位置確認後，再重寫敘事概念稿。

所有新設定先經討論與確認，再寫入母聖經或正式內容。未經確認的提案只保留在本補充論述中。

## 1. 名詞與篇幅尺度

### 1.1 正式使用層級

| 層級 | 定義 | 是否直接呈現在遊戲中 |
|---|---|---|
| 世界階段／長期篇域 | 港灣、國家、五國共域、主大陸、外洋、星空與星際文明等長期尺度 | 不一定 |
| 大章 | 一段完整的主要劇情篇章；第一大章首次通關約 10–12 小時 | 是 |
| 敘事階段 | 作者端用來控制起承轉合的八個結構分段 | 不一定 |
| 小幕 | 玩家實際遊玩的一次劇情小主線；具備獨立標題、目標、衝突、結果與下一幕鉤子 | 是 |
| 節點 | 小幕內的最小單位，例如對話、調查、移動、戰鬥、整備或結算 | 視類型而定 |
| 可反覆關卡 | 由主線小幕解鎖的重複遊玩內容，不計入主線小幕總數 | 是 |

母聖經原本使用「8 幕重大主線章程」與「28–32 個主線劇情節點」。本輪統一為：

- 保留八個作者端的「敘事階段」。
- 將 28–32 個玩家主線單位正式稱為「小幕」。
- 每個小幕內再拆成數個節點。

### 1.2 第一大章規模

**已定案：**

- 28–32 個主線小幕，以 30 個作為目前的中位設計值。
- 主線文本約 7–10 萬字。
- 首次通關約 10–12 小時。
- 約 14–18 場首次主線戰鬥。
- 約 6–8 個可反覆刷取關卡。
- 約 4 個階段首領與 1 個終局首領。
- 角色個人劇情與 R18 內容另計。

依總文本量平均估算，每個小幕約對應 2,300–3,300 字主線文本。目前採用的單篇約 2,500 字敘事概念稿，可視為一個標準小幕的語氣與內容原型。

### 1.3 小幕最低敘事規則

每個小幕必須具備：

1. 一個明確目標。
2. 一個阻礙或利益衝突。
3. 至少一項遊戲行為：調查、移動、戰鬥、編隊、整備或關係互動。
4. 至少一項狀態變化。
5. 一個推動下一幕的問題或結果。

狀態變化至少影響以下一項：

- 情報：角色知道了什麼。
- 關係：誰信任、支持、利用或敵視昭黎。
- 權限：昭黎能進入何處、接觸何物、使用何種航線。
- 資源：取得船、裝備、核心、物資或人力。
- 威脅：事件如何升級或改變方向。
- 身分：昭黎如何從普通人逐步成為船長。

## 2. 第一大章固定終點

**已定案：**第一大章在終局首領戰後結束，昭黎取得進入深海航線的合法許可。

章末昭黎應同時取得：

- 自己的船。
- 合法船長身分。
- 第一批因各自理由選擇同行的夥伴。
- 近海、島鏈與五國港口的基礎航行資格。
- 進入指定深海航線的特殊許可。
- 與舟域技術或返航事件相關、但仍受限制的長期任務。

終局首領與許可之間必須存在直接因果。昭黎不能因為「打贏所以被獎勵」，而是要透過終局行動證明：

1. 舊有處置方式已不足以解決新局勢。
2. 昭黎具備承擔船長責任的能力。
3. 讓昭黎在限制下出航，是各國均可接受、且比彼此爭奪更低成本的方案。

章末出航不是直接耗盡深洋篇，而是正式開啟更大的活動範圍、航行制度與後續成長。

| 8. 終局與出航 | 3 | 合 | 進入終局航道、擊敗首領、形成新的政治處置 | 昭黎取得船、夥伴及指定深海航線許可，正式出航 |

### 3.1 四段核心問題

- **起，第 1–7 小幕：**返航物是需要救援的人，還是可能危及港灣的威脅？
- **承，第 8–15 小幕：**誰有資格決定返航物、倖存者與相關情報的處置？
- **轉，第 16–23 小幕：**當各國都曾在不同程度上隱瞞或違反公開秩序，現行制度應如何繼續存在？
- **合，第 24–30 小幕：**當舊制度無法處理新局勢，誰能承擔第一次受控認知下放與合法出航的代價？

具體首領身分、五場首領戰的分布與每個小幕內容尚未定案。

## 4. 世界物理封界與長期航行原理

### 4.1 已確認方向

深洋存在真實的物理封界。普通船隻無法直接進入深海區域；高階強者可以依靠自身力量，在封界外側或深洋海面短暫活動，但無法輕易保護整艘普通船長期航行。

世界存在某種尚未正式命名的「界壓」或同類機制：

- 正常陸地、港灣與近海的界壓較低。
- 越過陸棚並接近深洋後，界壓急遽提高。
- 極高空與星海可能存在性質相近的界層。
- 普通生命與大型複雜結構無法長期維持完整。

個人強者可用穩定的身心與力量形成短暫的個人界域。大型船艦則需要把保護擴展至船體、船員、貨物、武器與船內環境，因此需要穩定的人工舟域技術。

### 4.2 海洋到星海的載具演進

同一艘主角船可以依序演進：

1. **海航形態：**在港灣、陸棚與島鏈活動。
2. **越海形態：**具備承受深洋界壓的能力。
3. **凌空形態：**不再依賴海水浮力，沿高空界流航行。
4. **星航形態：**在星海中維持適合生命與戰鬥的完整船內環境。

如此可使「船」從第一大章一路延續到星際文明，而非在海洋篇結束後被另一種交通工具取代。

深洋封界與高空／星海界層是否確實源自同一套機制，目前是已同意的上層設計方向，但封界的製造者、目的與最終真相仍待後續決定。

## 5. 諸國認知與檯面封鎖

### 5.1 諸國並非同樣無知

**已確認方向：**各國最高層已經能透過自己的手段取得深海航線資料、封界數據與有限情報。檯面上的封鎖不代表國家完全無法接觸深洋。

可能使用的手段包括：

- 高階強者短時間越界或在深洋海面活動。
- 在封界週期內投放觀測器與一次性設備。
- 使用高成本、不可量產的特殊載具。
- 從歷史遺物、失敗試驗與祕密航行取得航圖。
- 在已知薄弱區域設置國家級觀測設施。

各國仍未解決的共同瓶頸是：

- 可量產的舟域核心。
- 能長期承載普通船員的穩定船艦。
- 可公開商用、可重複驗證的深海航線。
- 不依賴鎮國級強者或國家設施的航行方式。
- 封界目的與星海關聯的完整解釋。

### 5.2 四個認知名詞

- **情報：**原始觀測資料，例如航線、界壓數值與失蹤紀錄。
- **知識：**經反覆驗證的規律，例如何種實力可停留多久。
- **認知：**足以重新解釋世界的上層模型，例如封界可能是人工系統。
- **技術：**能穩定重現的實際能力，例如可量產的舟域核心。

取得新情報不等於獲得新認知；取得新認知也不等於立即擁有可重現的技術。

### 5.3 公開敘事與封鎖目的

檯面封鎖同時具備：

1. 保護無法承受界壓的普通人。
2. 防止民間以大量生命進行無序試驗。
3. 維持國家對深海資料、航線與高階認知的壟斷。
4. 避免任何一國公開擴大祕密能力而引發軍備競賽。
5. 維持既有制度的正當性，避免承認各國長期存在檯面下的突破行動。

「認知不下放」是長期世界矛盾之一。第一大章事件不是讓所有真相公開，而是第一次將已不再具有決定性優勢、且對民間安全必要的部分認知有限下放。

## 6. 救援事件中的情報取得

### 6.1 公開可見資訊

港口居民、商船與普通官員可確認：

- 返航物來自封界方向。
- 存在倖存者與異常器物。
- 人員或船體呈現與界壓相關的痕跡。
- 官方啟動高規格封鎖與檢疫。

這些事實無法完全抹除，只能控制公開解釋。

### 6.2 五國與公議署的共同取證

救援與檢疫階段可共同取得：

- 救生艇或返航物的材料與受損狀況。
- 倖存者的基本身分、生理狀態及客觀航行時間。
- 核心的外部結構、能量反應與有限運轉資料。
- 返航物進入關口前的航跡。
- 無法輕易偽造的越界證據。

因此，各國不需要在後續航行中各派一人常駐昭黎的船，才能得知核心是否存在及是否運作。

### 6.3 各國的獨立判讀手段

| 勢力 | 主要手段與既有優勢 |
|---|---|
| 瀾國 | 船體結構、軍用材料、造船技術與失蹤艦紀錄比對 |
| 南泊聯邦 | 船員、資金、保險、商路與地下採購網絡 |
| 承國 | 物資調度、官員往來、工造紀錄與跨國情報交換 |
| 朔庭 | 高階強者對殘留界域、身體負荷與力量痕跡的直接感知 |
| 岱岳盟 | 遠距觀測、地脈記錄、封界週期與核心結構推演 |
| 止潮公議署 | 救援紀錄、檢疫報告、歷年事故、航籍與公開測試資料 |

### 6.4 仍需爭奪與調查的資訊

- 倖存者不願公開的完整證詞。
- 遠航途中真正發生的事件。
- 核心內部未能解讀的結構。
- 返航物穿越封界的最後條件。
- 封界另一側的完整航線。
- 祕密遠航參與者的真實目的與彼此關係。

## 7. 舟域核心的戰略價值

### 7.1 已同意定位

昭黎接觸的核心不是唯一的戰略突破物，也不是等同核武控制權的決定性資產。

暫定描述為：

> **破損的次級舟域核心：能在已知航線提供有限穩定與連續記錄，無法單獨突破封界；內部可能存在更高層認知，但其真實價值尚未獲得證明。**

核心可能具備：

- 在受控航線上減輕部分界壓。
- 保護中小型船短時間活動。
- 記錄封界另一側的殘缺數據。
- 保存尚無法理解的運轉結構或痕跡。

核心不具備：

- 單獨打開物理封界。
- 自由選擇深海航線。
- 讓普通艦隊立即長期航行。
- 被拆解後直接複製。
- 立刻改變任何一國軍事優勢。

各國可能從核心獲得更高認知，也可能只得到無法重現的孤例。其預期收益不足以讓一國承受其他各國共同敵對的代價。

### 7.2 妥協的根本邏輯

各國接受昭黎參與後續航行，不是因為慷慨，而是因為：

1. 讓競爭國獨占核心會改變均勢；讓尚未形成戰略威脅的昭黎使用，不會立即改變國力。
2. 各國已有自己的深海資料與手段，核心只提供邊際價值。
3. 核心需要在實際航行中持續運轉，才可能產生新資料。
4. 強行拆卸、扣押或封存可能降低研究價值。
5. 任何一國公開強搶，都會觸發其他國家的阻止與制裁。
6. 昭黎初期仍依賴五國港口、維修、校準、航圖與航線許可，難以把核心轉化成獨占優勢。

昭黎的角色更接近「互相否決後的中立試驗載體」，而不是被國家贈與唯一國寶的幸運平民。

## 8. 船上監督與夥伴組成

### 8.1 已確認修正

取消「五國各派一名正式代表常駐昭黎船上」的預設。

理由為：

- 救援當下已完成第一輪共同取證。
- 核心不是各國唯一的情報來源。
- 各國都有自己的深海手段與資料。
- 各國不願在共同船艦上暴露自己的祕密方法。
- 按國家配額安排船員會使隊伍失去正常運作與人物關係的自然性。

夥伴應因個人經歷、需求、承諾與選擇登船。角色可以具有國家、組織或家族背景，但不能只作為「某國派來的代表」。

### 8.2 保留的三種監督選項

以下選項全部保留，尚未定案：

#### 選項 A：無常駐代表＋航誌與港口稽核

- 核心使用受到共同封印或防拆制度限制。
- 每次申請航線時，只核發該航次需要的部分航圖與條件。
- 返港後接受檢查、航誌抄錄與核心狀態驗證。
- 重大資料由公議署封存並依盟約提供同等副本。
- 違規者失去航線、港口、校準與維修資格。

優點是夥伴組成最自然，昭黎的船保持私人船性質。缺點是需要設計可信的稽核與違約代價。

#### 選項 B：一名止潮公議署觀察員

- 不由五國各自派遣，只設一名共同制度代表。
- 觀察員負責記錄與程序，不直接指揮船長。
- 該角色仍需具備獨立人格、利益與角色弧，不能只是監視器。

優點是制度衝突可以直接存在於隊伍內。缺點是容易讓公議署成為默認資訊中心。

#### 選項 C：港口輪調的短期檢查員

- 沒有永久官方船員。
- 船隻進入不同港口或特殊航段時，由當地安排短期檢查員或引導員。
- 不同地區可以呈現不同制度與利益衝突。

優點是能展示各國差異。缺點是角色數量與敘事成本較高。

目前不選定其中一項，也不排除以 A 為常態、B 或 C 僅在特定事件短期使用。

### 8.3 初始夥伴加入原則

可採用的個人動機包括：

- 倖存者希望尋找失蹤主船或其他成員。
- 技術人員希望證明自己的舟域理論。
- 戰鬥角色因責任、承諾或對原組織處置的不滿而同行。
- 航海者想成為第一批取得新式民間航線資格的人。
- 醫療或檢疫人員認為船上仍存在未解風險。
- 某人以個人選擇登船，但仍可能隱藏其他任務。

夥伴必須先作為人物成立，再承載政治關係。

## 9. 有限認知下放

### 9.1 第一大章可以公開的內容

- 深潮線外存在可測量的物理界壓。
- 高階強者能短暫抵抗，普通人不能。
- 舟域核心確實存在，但目前無法普遍量產。
- 民間可以透過考核取得有限航線資格。
- 接近封界需要接受檢疫、記錄與監督。

### 9.2 仍不下放的內容

- 各國掌握的祕密航線。
- 封界薄弱週期的精確時間。
- 各國完整實驗結果與失敗代價。
- 高階強者真正能深入的距離。
- 封界可能是人工造物的完整證據。
- 海洋封界與高空、星海的關聯。
- 祕密遠航參與者與資助者名單。

### 9.3 開始下放的利益理由

- 返航事件已有大量目擊者，完全否認的成本提高。
- 民間黑市已開始交易真假航圖，維持完全無知反而增加風險。
- 各國都希望培養自己的民間航行力量，但不願率先公開違約。
- 共同許可制度可以把下放內容限制在安全、過時或非決定性的層級。
- 民間船隊蒐集低階資料的成本低於國家祕密艦隊。
- 面對封界未來的變化，諸國需要更多理解基礎規則的人。

這不是全面開放，而是由國家競爭、公共安全與制度正當性共同推動的受控下放。

## 11. 地圖製作順序

**方向同意：**先畫結構，再固定距離與劇情路線。

### 11.1 世界物理結構剖面圖

需要表現：

> 主大陸 → 港灣 → 陸棚近海 → 島鏈關口 → 物理封界 → 深洋 → 高空界層 → 星空

用途是確認：

- 水域與封界的空間關係。
- 普通船、強者與舟域船的活動範圍。
- 海航、越海、凌空與星航的共同原理。

### 11.2 五國共域圖

需要表現：

- 五國相對位置。
- 海岸、河流、山脈與陸棚。
- 島鏈航路與至少三類深洋關口。
- 商港、軍港、檢疫港、觀測設施與主要合法航路。

### 11.3 第一大章地區圖

需要表現：

- 昭黎所在港城或關口港。
- 鄰近聚落與港口功能分區。
- 救援航道、檢疫區與返航物路線。
- 八個敘事階段所需的主要行動地點。
- 各地點之間的航行時間，而非先任意固定里程。

## 13. 一致性護欄

後續設計不得違反：

- 諸國最高層不是對深洋一無所知。
- 核心不是唯一且立即可用的文明突破按鈕。
- 各國妥協源自互相否決、邊際收益與衝突成本，不是突然信任昭黎。
- 民間認知下放是有限、受控且具有國家利益理由的政策變化。
- 昭黎的夥伴因人物動機加入，不按國家名額配置。
- 第一大章必須在終局首領後，以昭黎取得自己的船、夥伴及深海航線許可作結。
- 地圖與物理結構未確認前，不固定港口、封界與深洋的精確距離。
- 概念稿只用來驗證方向，未經核准不得反向成為世界觀正史。
