## 0. 文件使用規則

本文件用來回答所有下層創作都必須服從的問題：世界如何運作、國家為何存在、力量如何受限，以及人物為何會作出某種選擇。

設定分為三種狀態：

- **已定案**：除非出現根本矛盾，後續創作不得任意推翻。
- **工作設定**：目前採用，但允許在細化時更名或調整。
- **待決設定**：只記錄問題與必要條件，不預先填入答案。

設計順序固定為：

> 世界物理結構 → 文明分布 → 海陸交通 → 力量規則 → 國家形成 → 國家利益 → 歷史事件 → 第一大章 → 幕與節點 → 場景文本

下層設定若與上層衝突，優先修改下層，不為了保留單一情節扭曲世界邏輯。

## 1. 作品核心

### 1.1 玩家體驗

玩家以固定主角的視野進入世界，從一片有限的陸地與港灣出發，在冒險、戰鬥與關係中成長，逐步走向海洋、星空，最終抵達星辰大海。

長期尺度為：

> 港灣 → 國家 → 五國共域 → 主大陸 → 外洋 → 其他陸塊與文明 → 星空 → 星際文明

每次尺度擴張都必須重新改變玩家對既有世界的理解，而不只是換一張更大的地圖。

### 1.2 敘事底色

- 中式文化氣質，但不複製廢材、退婚、扮豬吃虎與降智反派等套路。
- 故事中的每個重要人物都有立場、追求、已知情報與可承受代價。
- 主角不是因為周圍人愚蠢才顯得正確。
- 制度可以冷酷但必須有形成理由；反抗制度也必須支付代價。
- 強者、強國與長期存在的組織必須具備與其地位相稱的判斷力。
- 敵對不等於邪惡，合作不等於信任。
- 重大勝利應來自改變局勢、利益或資訊結構，而不是對手突然犯蠢。

### 1.3 主角與玩家

**已定案：**

- 主角具有固定靈魂、人格與主線選擇，玩家不能任意改寫主線方向。
- 玩家可選擇主角外觀呈現，主角的核心人格與劇情不因性別改變。
- 玩家透過主角的視角喜愛、理解並建立與其他角色的關係。
- 感情敘事不以玩家選擇的主角性別作為核心限制。

## 2. 世界尺度與地理母型

### 2.1 世界不是孤立大島

**已定案：採用「大陸東南半島」地理母型。**

第一階段的五國共域只是龐大主大陸的東南區域，不是整個已知世界，也不是一塊四面環海的封閉大島。

- 北方與西方繼續連接主大陸腹地，存在其他文明、國家與交通路線。
- 東方與南方具有廣大海岸、海灣、河口、半島與島鏈。
- 沿岸淺海和島鏈航路長期繁榮。
- 遠離陸棚之後才進入受限制的深洋。
- 五國的外洋制度只是世界海洋秩序的一部分，其他地區可能存在不同制度。

這個結構為未來保留三條擴張方向：

1. 向北、西進入更廣大的陸地文明。
2. 向東、南突破深洋，抵達其他陸塊。
3. 由深洋異象與遠古航路逐步銜接星空文明。

### 2.2 三層地圖制度

後續地圖分為三種尺度，避免把地區圖誤當世界圖：

1. **世界圖**：主大陸、其他陸塊、主要海盆、文明圈與未知區域。
2. **五國共域圖**：國界、地形、河流、資源、港口、道路、合法航路與深洋關口。
3. **第一大章地區圖**：主角所在港城、鄰近聚落、救援航道、檢疫區與無籍船返航路線。

在世界圖完成以前，不固定五國精確國界；在五國圖完成以前，不固定第一章城市相對距離。

## 3. 海洋秩序

### 3.1 禁止的不是海，而是深洋

**已定案：沿海國家不因外洋管制而衰弱。**

近海航運、漁業、鹽業、造船、海軍、港口金融與島鏈貿易均為合法且成熟的產業。沿海國家依靠這些產業成為五國中最富裕、最具技術與投射能力的勢力之一。

海域暫分為：

- **內水與港灣**：國家直接管轄。
- **近海陸棚**：合法商運、漁業與軍事巡航區。
- **島鏈航路**：連接各國與共管港口的主要貿易帶。
- **深潮線**（工作名）：海底陸棚急遽下降、海象與生態明顯改變的界線。
- **外洋／深洋**：越過深潮線後的受管制海域。

深潮線沿整個陸棚外緣延伸，不以東西南北決定。因此東、南、西南等方向都可能存在外洋關口。

### 3.2 外洋關口

「止潮列島」是工作名，指五國在東南海域共同管理的一組島鏈、檢疫港、巡航基地與觀測站。它不是全世界唯一的關口。

未來至少需要三類關口：

- 東方關口：第一大章無籍船的返航方向。
- 南方關口：受南部海商與島鏈勢力影響。
- 西南關口：連接其他文明圈或不同外洋制度。

每一處關口都應有不同的國家利益、管理方式和歷史問題。

### 3.3 航籍制度

外洋船舶必須具備可驗證的：

- 船籍與所有權
- 船員名冊
- 核准任務與預定航路
- 出航時間與返航窗口
- 貨物、樣本與特殊器物申報
- 返航預告與指定檢疫港
- 航行紀錄封存方式

缺少上述資料、蓄意隱匿航路，或在禁航區失聯後突然返航者，均可被判定為「無籍船」。

### 3.4 禁止直接接觸無籍船的必要理由

接觸禁令必須同時符合公共安全與國際政治邏輯，不能只建立在迷信上。

**已定案的原則：**

1. 無籍船可能攜帶外洋污染、疾病、生物、異常物質或未知現象。
2. 無法確認其國籍、真實任務、船員身分及是否遭到控制。
3. 航圖、技術、資源與樣本可能立刻改變五國力量平衡。
4. 任何單一國家率先登船，都可能被其他國家視為奪取戰略資產。
5. 標準處置應是隔離、監控、引導至共管檢疫區，而不是不分情況直接擊沉。

**待決設定：**

- 歷史災難的確切性質。
- 外洋污染是生物、能量、認知現象，還是多者疊加。
- 返航船是否可能成為某種定位、追蹤或「回應」媒介。
- 標準檢疫技術與當代科技／術法水準。

## 4. 五國共域的政治框架

### 4.1 國家數量與名稱

第一階段暫以五個主要國家與一個共管機構構成政治核心。國名均為工作名，可整體更換。

| 工作名 | 地緣位置 | 核心力量 | 外洋制度下的主要利益 |
|---|---|---|---|
| 瀾國 | 東部海岸與主要深水港 | 海軍、造船、港口、東方航道 | 從合法關口與航運集中獲利；同時最有能力秘密突破盟約 |
| 南泊聯邦 | 南部海灣、河口與群島 | 商船、金融、保險、航海技術 | 希望有限開放、建立特許航線，削弱瀾國的關口優勢 |
| 承國 | 中央河流平原 | 人口、糧食、工造、河運與行政 | 維持均勢，防止海權國家依靠外洋資源突然壯大 |
| 朔庭 | 北部高原、草原與冷水海岸 | 陸軍、戰馬、鋼鐵與邊防體系 | 公開支持限制海權，私下追求足以縮小差距的海洋技術 |
| 岱岳盟 | 西部高原、山地與河流上源 | 礦產、河源、觀測與學術城邦 | 取得觀測、檢疫與樣本研究權，維持知識與資源議價能力 |
| 止潮公議署 | 東南共管島鏈與各國派駐據點 | 檢疫、巡航、檔案與協調權 | 證明自身不可替代，維持五國對共同制度的依賴 |

### 4.2 沿海國家不得弱化

瀾國與南泊聯邦不是受到內陸壓迫的弱小沿海勢力，而是兩種不同海權模式：

- 瀾國偏向國家海軍、造船工業、軍港與關口控制。
- 南泊聯邦偏向商船網絡、港口自治、金融、保險與跨國資本。

承國能在總人口、糧食與製造上壓過單一海權國家；但若失去瀾國與南泊的港口、船隊和海運，其國力同樣會受到重創。

五國關係應是相互依賴又彼此防範，不設置一個在所有維度上壓倒其他國家的全能帝國。

### 4.3 國家合作的最低邏輯

五國不能因劇情需要而無條件配合。任何盟約必須具備：

- 可見利益
- 可驗證義務
- 違約代價
- 退出成本
- 危機處置程序
- 防止單一國家獨占成果的機制

五國願意合作的根本條件是：

> 在目前格局下，合作的收益仍高於公開背叛；但這個差距正在縮小。

無籍遠航隊的存在意味著，至少有一個國家的某個權力集團已經判斷：秘密違約可能比繼續遵守盟約更有價值。

### 4.4 國家決策檢查表

每次書寫國家、政府、軍方或大型組織的重大決策時，必須能回答：

1. 它想得到什麼？
2. 它害怕失去什麼？
3. 它掌握了哪些情報？
4. 哪些情報是錯誤或缺失的？
5. 它能承受多少代價？
6. 它受到哪些國內派系、法律、承諾與時間限制？
7. 它為何不選擇另一個看似更好的方案？
8. 這項選擇的最壞結果是什麼？

無法回答時，不得直接使用「君主昏庸」「官僚腐敗」作為萬用理由。

## 5. 力量體系的上層約束

### 5.1 個人與國家的關係

**已定案的方向：**個人強者能左右戰場與政治，但陸地篇的常規強者不能隨意單人消滅成熟國家。

國家力量由以下部分共同構成：

> 頂尖強者＋中堅軍隊＋戰陣與設施＋武器與艦隊＋情報後勤＋盟友＋制度正統性

這使國家能限制強者，強者也能迫使國家尊重其存在。雙方是互相利用與制衡，不是單向服從。

### 5.2 暫定功能級距

正式名稱、修行原理與數值仍待設計，現階段先固定各級對世界造成的功能影響。

| 功能級距 | 對現實局勢的影響 |
|---|---|
| 常人／正規兵 | 依賴武器、訓練、編制與協同 |
| 修行戰士 | 能穩定對抗普通戰鬥小隊，是早期角色的主要層級 |
| 戰術強者 | 能控制局部戰場、突破要點或斬殺重要目標 |
| 戰陣級強者 | 能改變大型戰鬥，但仍受軍陣、艦炮、消耗與同級強者限制 |
| 鎮國級強者 | 屬於國家戰略威懾，能決定戰役，不能獨自長期征服完整國家 |
| 越海級存在 | 陸地篇近乎傳說，具備深入深洋或無視部分常規限制的能力 |

陸地第一大章原則上不讓主角抵達鎮國級；鎮國級人物可以存在，但應作為世界上限、政治威懾或極少數事件參與者。

### 5.3 力量與心智能力

高階力量不能只是能量總量增加。晉升必須要求並強化某些心智能力：

- 感知與注意力分配
- 記憶與信息處理
- 對力量的精密控制
- 壓力下的自我一致性
- 對因果、風險和環境的判斷

高階人物可以傲慢、偏執、殘酷、保守、受感情影響，也可以因錯誤前提作出錯誤決策；但不能因透明謊言、廉價挑釁或作者需要而突然失去基本判斷力。

合理的失敗來源包括：

- 情報不完整或遭到高成本欺騙
- 價值排序與對手不同
- 時間、地點或制度限制
- 對手願意支付超出預期的代價
- 必須在數個壞選項中作出選擇
- 個人理性與組織理性互相衝突

### 5.4 遊戲戰鬥與劇情戰力

為避免抽取角色破壞主線邏輯，暫採以下原則：

- 玩家擁有角色，不代表該角色在每一段主線中都實際隨行。
- 關卡中的自由編隊屬於玩法層的戰鬥表現；劇情層另行標記實際參戰者。
- 角色稀有度不直接等於世界觀戰力。
- 高稀有度可以代表完成度、特殊機制、角色版本或培養價值，而不是人人都是鎮國強者。
- 重大劇情戰鬥需要記錄參戰者、情報、環境、限制與勝利代價。

## 6. 第一大章的上層框架

### 6.1 規模

**已定案：採用 B 型規模。**

- 8 幕重大主線章程
- 每幕包含多個小劇情節點
- 約 28–32 個主線劇情節點
- 主線文本約 7–10 萬字
- 首次通關約 10–12 小時
- 約 14–18 場首次主線戰鬥
- 約 6–8 個可反覆刷取節點
- 約 4 個幕級首領與 1 個終局首領
- 角色個人劇情與 R18 內容另計

### 6.2 已確認的開篇前提

- 五國外洋秩序已運作多年，且曾真正避免災害與戰爭。
- 某個沿海國家的權力集團曾秘密派出無籍遠航隊。
- 遠航隊失聯多年後，其中一艘船突然返航。
- 返航船沒有合規身分、申報資料與檢疫條件。
- 各國都不能接受競爭者獨占船、乘員、航圖與貨物。
- 主線將由陸地與港灣危機開始，結束時正式開啟海洋階段。

### 6.3 尚未固定

- 秘密遠航隊由哪個國家的哪個派系派出。
- 遠航真正目的。
- 船上倖存者、貨物與異常現象。
- 主角的正式身分、家庭與既有關係。
- 第一大章最終政治處置。
- 主角如何取得出海資格，以及是否被除籍、放逐或納入共管船隊。

## 7. 遊戲與角色內容原則

### 7.1 基本循環

> 劇情 → 冒險 → 戰鬥 → 養成／刷取 → 關係深化 → 角色內容解鎖

角色、隊伍構成、裝備配置與反覆刷取是長期遊戲時間的核心。現有玩法原型只用來驗證循環，不視為正式世界觀與主線正史。

### 7.2 角色取得

- 部分角色透過抽取取得。
- 部分角色透過活動或主線取得。
- 特別強或特殊的角色可要求長期培養與刷取。
- 取得方式應與角色的敘事定位、玩家投入時間和情感價值協調。

### 7.3 R18 內容

- R18 內容是角色關係與玩家喜愛的延伸，不替代角色塑造。
- 玩家應先因角色的人格、經歷、互動與成長而產生情感，再願意投入解鎖。
- 主要優先順序為：角色喜愛與投入所帶來的獎勵感，其次是關係發展，再與養成或活動結構結合。
- 主線不能把角色寫成只為成人內容服務的空殼。

## 9. 下一輪優先決策

依賴順序如下：

1. 世界力量來源：力量究竟來自身體、精神、天地、器物、契約，或混合體系。
2. 陸地篇戰力上限：鎮國強者與軍隊、城市、艦隊的精確制衡關係。
3. 主大陸與五國共域的地形骨架：山脈、河流、陸棚、海流與三處關口。
4. 五國形成史與政體：地理如何塑造政權，而不是先決定標籤再填地理。
5. 歷史外洋災難與盟約條文。
6. 第一大章的國內派系、返航船與主角位置。
