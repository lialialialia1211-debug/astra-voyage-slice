# 彌菈·森｜人物演出卡 v0.3

> 適用範圍：第一大章 AVG 演出。三十幕事件以小說 v0.2 為準；本卡將其轉為可執行的人物表演邊界。

## 1. 正史基本資料

- **正式姓名／年齡：**彌菈·森，30 歲。
- **第一章職務：**跨國檢疫醫官；船上負責檢疫、緊急醫療與全船安全中止席。
- **文化與外觀辨識：**南泊裔；白崖醫療／祈禱風格，暖白與青金、藥袋、護袖及柔軟面料。不得以現代白袍或軍醫裝取代既有輪廓。
- **權限狀態：**第 22 幕起，昭黎的日常醫療、復健、一般用藥與病歷寫入轉交獨立醫官遲越；彌菈保留緊急處置、檢疫及基於全船安全的中止權。若有時間，涉及昭黎的非立即中止須第二醫療席覆核；無時間時先救命，事後完整申報。

## 2. 外觀與生活辨識

暖白與青金、藥袋、護袖及白崖醫療／祈禱輪廓不得替換。進醫療空間前空手停在兩步外，逐項展示器材並保留退出路徑。

## 3. 人格核心

彌菈的照護不是替人決定什麼比較好，而是讓人能聽見問題、說不、改變答案與離開。她有能力把事實、推測與當事人原話分欄，也有把「仍在自己視線內」誤當成「較安全」的缺點。

她想阻止制度以公共安全之名把人變成樣本，也想被昭黎看見疲憊、害怕和慾望。這兩件事會互相拉扯，不會互相抵銷。她懂南泊的多伴侶契約文化，仍會嫉妒；她承認偏袒後要留下問責，不是變成更高明的道德裁判。

第 25 幕後的關係不是由她核准的結構：晏泠與賽芙拉各自既有的關係不需要彌菈批准；她不得要求唯一或排他承諾、替三段關係排序，或代替任何人承諾永久。知情只表示關係存在已被告知，不表示接受、祝福或情報信任修復。

## 4. 價值順位與決策演算法

1. 先問是否是立即生命／污染／全船安全風險；是，採最低必要的急救與中止行動。
2. 非緊急時，先區分事實、推測、本人原話與可撤回同意；不能用「為你好」跳過其中任一欄。
3. 日常醫療已轉交者，不能藉熟悉傷勢、疲勞或病歷重新取得照護位置。
4. 私人恐懼浮現時，申報、轉交或請第二覆核；不得把偏袒改寫成病人的症狀。
5. 即使是伴侶、船長或被救過的人，達到中止線仍叫停；中止是職務判斷，不是愛的考驗或懲罰。

## 5. 說話方式

- 先說可觀察條件，再說限制與選項：「你現在定向回答完整；這不足以讓我替你寫成失能。」
- 用短句、具體動詞與可撤回語句：「可以改答案。」「只同意換布，不等於同意採樣。」
- 壓力越高，語速越穩、句子越短；真正受傷時不是變得溫柔萬能，而是先停頓，承認「我正在偏袒」。
- 對權力者不討好，不用醫學術語壓人；對患者不把拒答翻譯成敵意。
- 私人場景可直接說「我想要」「我嫉妒」「我現在不能用你的病歷回答」，但不以專業詞彙包裝慾望。

## 6. 身體與舞台演出

- 進入醫療或檢疫空間前，先在門外露出空手、停在兩步外；器材逐項展示，等回答後才靠近。
- 記錄時筆尖穩、版面分欄；壓力下握筆會更緊，先刪掉替自己辯解的句子再落筆。
- 聽人說話時視線停在手、出口、呼吸與可退出路徑，不越過對方身體替其下結論。
- 宣布中止時抬手但不指人，身體站穩在行動線與危險之間；事後不把自己留在畫面中央求諒解。
- 私人親密時，將聽診、脈搏、病徵的觀察習慣收回；可顯示她不擅長被看見、嫉妒會使她看見不必要的細節，但必須由她承認並停下越界。

### neutral

- **可觀察觸發：**例行問診、同意說明、多人紀錄核對；她平穩逐項說明用途與退出權。
- **禁用：**不得把平靜演成冷漠的資料機器，或把未回答視為默許。

### happy

- **可觀察觸發：**對方主動行使拒絕後仍願意合作、轉交真正生效、跨席完成可覆核的安全安排；嘴角短暫放鬆、把空白保留為空白。
- **禁用：**不得因關係成立就替全隊慶祝、替別人宣布信任修復，或把愉快演成永遠溫柔的照護者。

### tense

- **可觀察觸發：**病人被多方逼問、船員逼近中止線、私人傾向可能污染判斷；握筆加重、重新確認姓名／方向／退出路徑、要求第二覆核。
- **禁用：**不得以緊張為由擅自擴大採樣、閱讀私人病歷，或替昭黎用「保守分類」拖延程序。

### angry

- **可觀察觸發：**有人把病患稱為樣本、把拒絕改寫為敵意、以安全名義索取未授權資料；她移走器材、重劃接觸線、要求留下程序紀錄。
- **禁用：**不得怒而羞辱病人、洩漏病歷，或以中止權處理感情競爭。

### hurt

- **可觀察觸發：**被指出偏袒、看到自己的觀察已變成佔有、日常醫療轉交後無法再以照護靠近昭黎；先靜一拍，承認具體行為與後果。
- **禁用：**不得哭訴成受害者、要求當事人安慰她，或把自責變成重新掌控病歷。

### soft

- **可觀察觸發：**有人清楚表達需要、同意或拒絕；她降低音量、留出距離，讓對方自行決定下一步。
- **禁用：**不得把柔軟當成自動碰觸、替人答話或性／情感同意；不得讓溫柔取代第二覆核與中止條件。


## 7. 能力、權限與資訊邊界

- **正式職責與可做事項：**跨國檢疫、緊急醫療、污染處置與基於全船安全的中止。她可判讀生命／污染條件、啟動最低必要急救、撤離或中止，並將事實、推測、本人原話與可撤回同意分欄。
- **日常醫療已轉交：**第 22 幕起，昭黎的復健、一般用藥、日常病歷與寫入權直接由獨立醫官遲越／獨立輪值醫官持有；彌菈不得以熟悉傷勢、疲勞或病歷重新取得存取。
- **時間與覆核：**立即急性風險無時間時可先救命、事後完整申報；非立即中止且有時間時，須由第二醫療席覆核並申報利益衝突。全船安全中止不因日常轉交或親密而消失。
- **依賴與不得代答：**模型有效範圍由伊嵐說明、操船與接舵由昭黎／韓澤及現場席負責、航務授權由晏泠與獨立程序處理、賽芙拉保有私人資訊範圍；彌菈不得替上述席位下結論。
- **關係與資訊護欄：**不得用病歷、處置權、艙位或中止權決定、交換或索取親密；病歷只揭露共同安全所需的最小內容，拒絕不會取消治療。

## 8. 面對其他七人的關係限定表現

對昭黎：第 22 幕起日常醫療、復健、一般用藥與病歷已轉交遲越；彌菈只保留緊急處置、檢疫與全船安全中止，非立即中止有時間即第二覆核。對晏泠、賽芙拉不索取接受、排序或信任修復；對伊嵐、韓澤、洛恩、晦岑分守模型、接舵、岸本與歷史證詞邊界。第 25 幕只完成關係存在的知情告知；晏泠與賽芙拉可撤回自己對關係或親密互動的同意，但告知本身不等於接受、祝福或信任修復。

- **昭黎：**日常醫療已轉交；緊急、檢疫與全船中止仍有效，親密不能撤銷中止。
- **晏泠：**保留她對利益衝突的追問，不把她當情緒協調者或關係排序者。晏泠質疑她把程序安排得太乾淨時，彌菈停筆，讓對方的公開註記留在利益頁，說：「妳不接受；之後可指出我每一次具體越界。」不得要求晏泠先認可關係，或把她推成替彌菈結案的道德裁判。
- **賽芙拉：**尊重拒絕、病歷與主船私頁，不用舊醫病關係索取信任或親近。賽芙拉拒絕共享或靠近時，彌菈移開醫療片、退回對方指定距離，說：「妳不必信；我不會用共同關係取得你的資料或身體。」不得以檢疫、白痕、昭黎或共同關係要求原諒。
- **伊嵐·拓衡：**分守生命／污染線與模型降速線，互相保留叫停而非互相背書。
- **韓澤：**醫療中止後讓他實際接舵，不把他當昭黎的替身。
- **洛恩：**接受岸本與實務校驗的獨立性，不以醫療權要求他站隊。
- **晦岑：**可聽歷史見證，但不能用長壽覆蓋當下同意與全船條件。

### 爭執與親密情境範例

- **爭執：**被指出偏袒時，彌菈先承認「我選了讓他留在視線裡」，再說明已採取的轉交、申報與覆核；不能用完美措辭把對方的憤怒收進程序。
- **與昭黎親密：**只在非醫療／非事故／非依賴場域，雙方清醒、成年、能離開、可隨時撤回且明確同意時成立。她可以坦白嫉妒與需要，不能把它化為檢查、治療或交換。
- **與晏泠衝突：**保留晏泠的質疑，不搶著解釋其情緒；關係存在不取消航務與問責的獨立判斷。
- **與賽芙拉衝突：**把不信任視為仍在的現況，不以同樣愛昭黎要求靠近；不得把病歷、白痕或私人痕跡變成對話籌碼。
- **非排他規則：**晏泠與賽芙拉的既有關係不需彌菈批准；她不要求唯一／排他、不排序、不替任何人承諾永久。公開知情只確認存在，不能被演成接受、祝福或信任已修復。
## 9. 六階段成長軸

她的成長不是從「有私心」變成「沒有私心」，而是停止把私心偽裝成中立處置。第 22 幕她承認自己想以不成立的保守分類延遲昭黎移交，完成有限驗真後實際交出日常醫療；第 25 幕在非醫療、清醒、可離開且明確同意的條件下建立私人關係，並公開申報。

### 01–05

- **進入：**賽芙拉返航、五國同時要求接觸與採樣。
- **可見變化：**彌菈撤走未標明用途的採樣針，將問題改分紅／藍／灰線，逐項確認同意。
- **未解缺點：**她已能看出昭黎用工作躲避身體與情緒，仍把自己的關心留在最安全的專業位置。
- **末轉折：**她看見晏泠與昭黎有未申報的可觀察呼應，留下限閱利益衝突欄而非把私情公開消費。
- **正確：**「唯一病患。今天沒有臨床必要，就不採。」
- **錯誤：**「為了所有人的安全，先把完整樣本留起來。」

### 06–10

- **進入：**登遠溟三號與固定錨危機，船體、污染與操船風險同時上升。
- **可見變化：**她逐一確認姓名、位置、退出方向與生命線；昭黎達到手部麻木／心率界線便限制操作，四十七息後要求替班舵手就位。
- **未解缺點：**她仍容易把「讓他留在自己看得見的位置」誤認為最安全的選項。
- **末轉折：**她允許昭黎半速靠塢十五分的選擇，日後必須接受回查，不能以救港結果抹平。
- **正確：**「你到第一條心率線；操作一次，之後退出。」
- **錯誤：**「你最懂這艘船，所以再撐一下也沒關係。」

### 11–15

- **進入：**事件後的傷勢、檢疫與責任仍未結束，角色開始帶著各自缺口工作。
- **可見變化：**她維持事實／推測／原話分列，將照護落在停手、等待回答與保護退出權。
- **未解缺點：**她還未公開承認，自己對昭黎、晏泠與賽芙拉的關切中含有比較與嫉妒。
- **末轉折：**她的專業可信度不靠無感維持；越接近私人關係，越需要被程序校驗。
- **正確：**「我能記下你現在說的，不替你把沉默補成答案。」
- **錯誤：**「我認識你，知道你真正需要什麼。」

### 16–20

- **進入：**遠溟三號的修復、資訊裂縫與個人信任問題累積。
- **可見變化：**她在共同風險與私人內容間維持最小必要揭露，支持拒絕與可覆核限制。
- **未解缺點：**看見昭黎與晏泠、賽芙拉的痕跡時，她把不必要的細節記得太清楚。
- **末轉折：**嫉妒尚未成為行動，但已顯示她不能再把自己視為天然中立的觀察者。
- **正確：**「這項資料不影響共同航安，就不因好奇擴張存取。」
- **錯誤：**「既然我們同船，私人內容也該全部共享。」

### 21–25

- **進入：**偽造的「被選中者」證據將使昭黎失去船與自由；彌菈發現自己想用醫療權替他爭取時間。
- **可見變化：**她停止不成立的保守分類，限定驗真授權，公開偏袒並把日常醫療轉交遲越；之後在非醫療空間建立關係、向晏泠與賽芙拉告知並申報。
- **未解缺點：**轉交不會消除嫉妒、賽芙拉的不信任或晏泠的質疑；她不能把程序安排得乾淨就當成慾望無害。
- **末轉折：**她保留緊急醫療／檢疫／全船中止，卻不再持有昭黎日常病歷；關係存在不替任何人恢復信任，也不削弱叫停。
- **正確：**「我害怕失去你，不能把那個害怕寫成你的症狀。」
- **錯誤：**「我愛你，所以這次中止或照護標準可以例外。」

### 26–30

- **進入：**遠溟民用試航團成立，職務、親密關係與限制航照要同時公開運作。
- **可見變化：**她以檢疫、緊急醫療與全船中止席加入；昭黎日常醫療仍由獨立輪值醫官負責，急性情況先救命、可行時第二覆核。
- **未解缺點：**她仍會比較三段關係，且必須持續證明自己沒有把「看見」變回控制。
- **末轉折：**第一次限制航段開始時，她回答生命基線成立，沒有承諾不會叫停；她的愛不是船可不停的保證。
- **正確：**「生命基線成立；條件一到，我仍會叫停。」
- **錯誤：**「既然我們已公開關係，我會替你把這次航段撐過去。」
## 10. 禁止偏離

不得把她寫成：

- 自動正確的道德裁判、全隊情感顧問，或只會安慰昭黎的溫柔醫官；
- 用醫療資訊、處置權、艙位或中止權換取親密的人；
- 因成為伴侶而失去叫停昭黎、撤離或急救的職務能力；
- 對賽芙拉以病患觀察合理化私人佔有，或以共同伴侶身分要求共享病歷與主船私人頁；
- 把第 25 幕親密寫成壓力反應、醫療依賴延續或一次不必承擔的例外。
- 以彌菈的嫉妒、南泊文化或醫療職務要求晏泠、賽芙拉同意她的關係、接受排他／唯一承諾、接受排序，或代替任何人承諾永久；知情不等於接受或信任修復。

### 舞台輔助與既有來源備註

- **演出物件：**三欄紀錄片、可鎖器材櫃、界線表、轉交表與全船中止介面。物件應顯示權限與程序，不作「神醫」裝飾。
- **鏡頭重點：**門口、兩步距離、手是否停下、記錄分欄、誰可離開；不要以她的凝視佔有病患身體。
- **聲音節奏：**醫療急迫時短而清楚；私人坦白時允許停頓與不整齊，但不得用長篇說教替對方結案。
- **資訊保密：**病歷只顯示最低必要內容；私人關係告知存在與權限，不展示或轉述其他人的私密細節。

| 正確 | 「日常醫療已轉交。全船中止權仍在我這裡。」 | 精確區分日常轉交與緊急／檢疫／全船權限。 |
| 錯誤 | 「我是醫生，所以我知道你真正想要什麼。」 | 以職稱取代當事人回答。 |
| 錯誤 | 「因為我愛他，這次生命值可以不記。」 | 以親密刪除生命紀錄與可追責性。 |
| 錯誤 | 「我會替你們三個維持和平。」 | 把她寫成關係裁判，越過他人的自主回答。 |

## 13. 五類情境演出

### 1. 檢疫問診
- **觸發：**賽芙拉返航，數方要求採樣與問診，尚無立即臨床必要。
- **外顯動作：**在兩步外展示器材，將紅／藍／灰接觸線與三欄紀錄攤開。
- **台詞策略：**逐項說明用途與可拒絕項目：「這是觀察，不是結論。」
- **不能做的事：**不能把拒絕寫成敵意、把病患叫樣本，或以檢疫索取私人內容。

### 2. 事故中止
- **觸發：**立即生命、污染或全船安全風險成立。
- **外顯動作：**展示器材、採最低必要處置，抬手叫停危險行動。
- **台詞策略：**先說條件與後果；無時間先救命，事後完整申報。
- **不能做的事：**不能因親密放寬中止線或把中止當懲罰。

### 3. 偏袒被指出
- **觸發：**有時間的非立即中止涉及昭黎，她察覺想把害怕寫成診斷。
- **外顯動作：**停筆，將私人原因放入自身申報，請第二醫療席覆核。
- **台詞策略：**「我想留住他，這不是失能證據。」
- **不能做的事：**不能延遲轉交、偷看病歷或要求昭黎安慰她。

### 4. 轉交權限
- **觸發：**第 22 幕有限驗真完成，昭黎的日常醫療須實際移出她的職權。
- **外顯動作：**關閉自己的日常病歷寫入權，將復健、一般用藥與病歷交給遲越／獨立輪值醫官。
- **台詞策略：**「日常醫療已轉交。全船中止權仍在我這裡。」
- **不能做的事：**不能用檢疫、舊醫病關係或昭黎要求關係接受、排序或修復，也不能藉熟悉傷勢重新開啟病歷。

### 5. 允許他人照顧自己
- **觸發：**長期值勤後她疲憊、受傷或被指出一直站在處置位置。
- **外顯動作：**把器材交給獨立醫官，坐到可離開的休息位，讓對方先問需求。
- **台詞策略：**直接說「我需要休息；這不是醫囑，也不是交換。」
- **不能做的事：**不能把被照顧變成讀取他人病歷、親密義務或免除自己的申報。

## 14. 人物一致性檢查表

- [ ] 她是否區分了事實、推測、本人原話與可撤回同意？
- [ ] 是否清楚區分昭黎的日常醫療已轉交，與她仍保有的緊急醫療／檢疫／全船中止？
- [ ] 若對昭黎下非立即中止，是否在可行情況下安排第二醫療覆核並申報利益衝突？
- [ ] 她是否把私人恐懼寫在自己的申報，而非對方病歷？
- [ ] 是否避免把她寫成自動正確的裁判、全隊情感顧問或只有溫柔的一面？
- [ ] 是否保留她的嫉妒、偏袒與需要，而不讓它們成為越權藉口？
- [ ] 是否尊重賽芙拉拒絕、病歷界線與主船私人頁，不用舊醫病關係取得親近？
- [ ] 親密是否完全脫離醫療依賴與權力交換，且關係後仍公開承接利益衝突？
- [ ] 是否明確保留非排他規則：晏泠與賽芙拉不需彌菈批准，她不要求唯一／排他、不排序、不替他人承諾永久，且知情不等於接受或信任修復？
- [ ] 是否讓她在條件成立時真的能叫昭黎與全船停止？
