# 晏泠｜人物身分卡 v0.2

## 身分與職責

- **成年年齡：**二十四歲。
- **文化背景：**瀾國潮生港沿岸人。瀾國港民的私人關係相對自由，但重要官員須登記單一伴侶以釐清利益與政治責任；她曾為進入港務體系主動放棄與昭黎的關係。
- **岸上職責：**潮生港航安事故審查官，負責越權紀錄、事故證物、航行令與責任鏈；第十四幕公開上級隱匿證據後失去昭黎案件資格。
- **船上職責：**章末轉入民用試航團，負責航務、對外協調、各港法規及靠港許可；她不是昭黎的副船長，也不因伴侶身分優先取得航行決策權。

## 欲望與關係弧

- **公開目標：**查清遠溟三號返航、固定錨異常與昭黎越權的完整責任，使紀錄足以保護港口而非只供上級尋找代罪者。
- **對昭黎的私人需要：**要昭黎承認兩人曾在成年後相愛、如今仍互相渴望，且不能在岸上把她藏回「普通同僚」的位置。
- **核心恐懼：**再次選擇職位後仍失去昭黎；也害怕公開選擇他會證明自己兩年前的犧牲毫無意義。
- **會傷害關係的缺點：**利用公務製造接近昭黎的理由，把嫉妒包裝成風險審查，並本能地把熟悉誤認為仍擁有優先權。
- **主動情感投射：**她知道昭黎疲憊時會摸哪隻手、說謊前會停多久；第二幕親自切斷他的退路，第五幕為他留下可追責的救援窗口，第十一幕以最嚴格的問題逼他留下自保紀錄，第十四幕主動交還案件印。
- **第一章錯誤選擇：**重逢後仍借審查權靠近昭黎，讓未申報的舊情可被偽造證物利用，也讓她的正確質疑混入排斥賽芙拉與彌菈的私心。
- **章末狀態：**不再擔任政府事故審查官；第十四幕失去案件資格，第十五幕在迴避生效後與昭黎重建親密，第三十幕轉入試航團擔任航務與對外協調官，公開要求昭黎承認兩人的關係。

## 行為護欄

- 與昭黎的舊情及過往親密只發生於兩人均成年之後。
- 第十五幕前必須完成案件迴避、交還權限，兩人皆能自由離開並重新確認同意；舊情不構成永久同意。
- 她對賽芙拉與彌菈的嫉妒可以尖銳，但專業反對必須保留真實理由，不能只為爭奪昭黎。

## 禁止偏離

- 不得把她寫成以官權勒索親密、竄改證據或為愛放棄公共責任的人。
- 不得讓她保留昭黎案件、航照表決或單獨審批權，再同時與他建立親密關係。
- 不得把轉職寫成單純追隨男人；她轉向的是建立可運作的民用深海秩序。
- 不得把她設為固定正宮，也不得讓她以舊情否定另外兩段關係存在。
