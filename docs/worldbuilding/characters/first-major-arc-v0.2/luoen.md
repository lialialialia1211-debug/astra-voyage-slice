# 洛恩｜人物身分卡 v0.2

- **成年年齡：**四十二至四十八歲。
- **文化背景：**瀾國沿岸人，熟悉潮生港的混合船員社群、非正式港務人脈與事故責任鏈。
- **岸上職責：**資深引航救難員、救難艇「折蘆」船長；後期成為獨立航誌保管人及替班引航員訓練者。
- **船上職責：**前期教授昭黎近海操船與可接手的責任；第一大章後期不登遠溟三號，刻意保留岸上第二份答案。

## 欲望與關係弧

- **公開目標：**讓折蘆與潮生港每一班人安全交班，使事故判斷能由下一個人理解、反對與接手。
- **對昭黎的私人需要：**看見昭黎成為不必模仿自己的船長，也希望他明白被支持不等於可以免受校驗。
- **核心恐懼：**昭黎的能力成長得比制度與關係制衡更快，最後把親自承擔變成替全船決定。
- **會傷害關係的缺點：**太習慣以工具、舵位與工作表達關心，使昭黎很晚才知道自己被重視；保護原始紀錄時也可能顯得不信任同伴。
- **主動情感投射：**把關鍵舵位與工具交給昭黎表示認可，在越權後不替他抹去紀錄；停職危機中留岸保管原始航誌，使昭黎仍有獨立證據可自保。
- **第一章錯誤選擇：**早期只以工作逼昭黎成長，沒有明說支持與退出方式，使昭黎在審查壓力下更容易相信自己只能獨自負責。
- **章末狀態：**留在潮生港擔任岸上獨立航誌校驗者與替班訓練者；與昭黎從帶教關係轉為能互相問責的同業。
