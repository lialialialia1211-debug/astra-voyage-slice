# 伊嵐·拓衡｜人物身分卡 v0.2

## 身分與職責

- **成年年齡：**二十七至三十三歲。
- **文化背景：**岱岳盟觀測學城體系出身；重視原始值、可反駁假設與研究權限的利益衝突。
- **岸上職責：**派駐觀測官，研究界壓、固定錨點與移動舟域模型，保留可共享原始值與標示假設的推導頁。
- **船上職責：**負責核心觀測、航線模型與數據超標降速權；模型依賴昭黎的船況、賽芙拉的經驗與彌菈的生命反應。

## 欲望與關係弧

- **公開目標：**解釋核心、固定錨點與移動舟域的關係，使知識離開學城後仍能在現場接受檢驗。
- **對昭黎的私人需要：**需要昭黎把直覺轉成可校驗資料，也需要他在模型失效時指出實物因素，而不把伊嵐當作提供確定答案的工具。
- **核心恐懼：**完整模型被政治力量當成再次進行人體與核心試驗的許可。
- **會傷害關係的缺點：**為保留完整數據而拖延撤離，並低估帶有不確定性的說法會如何影響非研究者。
- **主動情感投射：**主動保留昭黎判斷與模型分歧的雙版本，公開讓數據推翻自己的假設；在終局把降速與中止條件寫入共享航線，而非要求船長信任自己。
- **第一章錯誤選擇：**登艦初期試圖多保留一段核心數據，幾乎壓縮撤離窗口；此後接受任何模型都必須先寫明停止條件。
- **章末狀態：**加入遠溟三號試航團，建立能在現場被推翻、修正並共享的移動舟域模型，保有獨立降速權。

## 禁止偏離

- 不得加入昭黎與三名女主的親密關係，也不得因情感主線放棄研究獨立。
- 不得寫成只解說世界觀的百科、不顧人命的刻板研究者或永遠正確的預測者。
- 不得讓昭黎一句直覺反覆推翻模型，也不得讓模型取代操船、醫療與情報判斷。
- 不得刪除誤差、原始值或停止條件來保護昭黎的權威。
