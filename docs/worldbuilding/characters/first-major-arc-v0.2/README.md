## 使用規則

- 所有主要人物均為成年人；親密關係只發生於意識清楚、能自由離開且明確同意的狀態。
- 昭黎、晏泠、賽芙拉與彌菈·森構成單一正史中的多伴侶關係，不拆分路線，也不設定固定排序。
- 私人關係不得覆蓋船長、航務、醫療、情報、研究、歷史見證與岸上校驗權限。
- 洛恩、伊嵐·拓衡與晦岑不加入多女主關係；他們支持昭黎時仍保留反對、停止、校驗與公開異議的能力。
- 每張人物卡的「禁止偏離」均為正文護欄；若後續必須修改，應先修訂本基準及三十幕細綱。

## 人物索引

1. [昭黎](zhaoli.md)：二十二歲；由潮生港初級引航救難員成為遠溟三號船長。
2. [晏泠](yanling.md)：二十四歲；潮生港航安事故審查官，昭黎的成年舊情人。
3. [賽芙拉](saifula.md)：外表二十四至三十歲；遠溟三號唯一已知倖存者與深洋航跡顧問。
4. [彌菈·森](mila-sen.md)：三十歲上下；南泊裔跨國檢疫醫官。
5. [洛恩](luoen.md)：資深引航救難員；昭黎的職業導師與岸上校驗者。
6. [伊嵐·拓衡](yilan-tuoheng.md)：岱岳盟觀測官；核心與航線模型負責人。
7. [晦岑](huicen.md)：海禁災難親歷者；固定錨點歷史見證人。

## 相對 v0.1 的基準變更

- 新增晏泠，並把她與昭黎成年後的舊情、案件迴避及章末轉職寫成主線。
- 賽芙拉的沉默從純粹的資訊自主擴展為會傷害任務的隱瞞，以及在可離開時主動留下的選擇。
- 彌菈由醫療守門人擴展為必須申報偏袒、轉交日常醫療並接受利益衝突問責的伴侶。
- 昭黎必須公開承認三段關係，不承諾虛假的平均分配，也不得以船長權限換取親密。
- 洛恩、伊嵐與晦岑維持原有專業邊界，不因新版情感主線降格為附和者。
