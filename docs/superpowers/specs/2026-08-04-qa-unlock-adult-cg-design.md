# QA 成人 CG 全解鎖設計

## 目標

在事件收藏提供一個明確的 `QA：解鎖全部 CG` 按鈕，讓目前的 GitHub Pages QA 存檔可直接閱覽三張成人 CG。

## 行為

- 按鈕只新增三個 `unlocked:<eventId>` 覆寫旗標。
- 覆寫旗標直接滿足對應事件的解鎖判定，不要求關係等級或戰鬥旗標。
- 不變更 AP、關係經驗、角色或武器等級、關卡進度、戰鬥結果及獎勵。
- 全部事件解鎖後，按鈕停用並顯示 `QA：CG 已全解鎖`。
- 手動解鎖事件的條件文案顯示 `QA 已解鎖`，不假稱已完成原始條件。

## 位置

按鈕放在事件收藏頁首導覽區，與返回艙室及顯示設定並列。此專案目前是公開的臨時 QA 原型，因此按鈕可直接顯示，不增加環境切換設定。

## 驗證

- 單元測試：`unlocked:<eventId>` 可繞過原始條件解鎖事件。
- UI 測試：點擊 QA 按鈕後三個事件都可開啟，且不修改無關狀態。
- 所有測試與建置只在 GitHub Actions 執行。
- 部署後只在固定 Pages URL 點擊並確認三張 CG 圖片完整載入。
