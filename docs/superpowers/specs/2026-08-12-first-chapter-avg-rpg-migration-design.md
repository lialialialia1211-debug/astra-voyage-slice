# 第一章 AVG＋RPG 漸進遷移設計規格

日期：2026-08-12

狀態：使用者已確認，可進入實作

## 1. 目標

保留現有網頁 RPG 的回合制戰鬥、四人編隊、主手武器、3×3 武器盤、六屬性、技能冷卻、奧義、連鎖、舟域援護、角色與武器 Lv.1–10、關係等級、AP、戰鬥快照與遠端 QA 基礎，將現有原型內容逐步替換為第一章 30 幕唯一正史。

第一個可驗收里程碑為：

```text
成年確認
  → 第1幕〈港鐘與舊情〉
  → 第2幕〈黑船返航〉
  → 戰鬥準備（昭黎六屬性主手）
  → 戰鬥1〈外灣救難線〉
  → 戰果與垂直切片完成畫面
```

美術未完成期間，所有新素材使用穩定 Asset ID 與可讀 fallback。美術方之後提供完整資料夾路徑時，只進行檔案驗證、轉檔、Manifest 更新與遠端畫面驗收，不改動劇情或戰鬥資料結構。

## 2. 正史與命名

- 唯一正史母稿為 `docs/worldbuilding/first-major-arc-novel-v0.2/` 的 30 幕小說。
- 不建立角色路線、分歧主線或多結局。
- 主角固定為昭黎，不再提供男性／女性艦長選擇。
- 正史顯示名沿用小說：昭黎、晏泠、賽芙拉、彌菈·森、伊嵐、韓澤、洛恩、晦岑。
- 程式與素材使用 ASCII 穩定 ID：`zhaoli`、`yanling`、`saifula`、`mila`、`yilan`、`hanze`、`luoen`、`huicen`。
- 美術規格曾使用「燕翎／米拉」簡寫；不更動素材 ID，但遊戲顯示名以「晏泠／彌菈·森」為準。
- 第一章第15、20、25幕的 R18 均為主線固定內容，不要求好感度。
- 未來新增角色的成人支線才要求主線進度與好感度門檻。

## 3. 漸進遷移策略

採用已確認的垂直切片策略，不做一次性大爆破替換。

### 3.1 共存期

- 新版第一章建立獨立章節資料與流程控制層。
- 現有 RPG 引擎仍是唯一戰鬥引擎。
- 舊原型內容暫留於程式內，確保尚未搬移的成長、編隊、武器盤、艙室與設定功能仍可引用既有介面。
- 玩家新存檔只從昭黎第一章入口進入，不再經過舊艦長選擇與招募序章。
- 每完成一個章節批次，才把對應舊資料與畫面從可達路徑移除。

### 3.2 完成期

- 30幕、15戰與6名正式隊員全部搬移後，刪除舊 `cap_m`、`cap_f`、`chr_01`～`chr_04`、舊地表關卡與舊事件資料。
- 刪除只能在新版內容、存檔遷移、遠端測試全部覆蓋後進行。

## 4. 第一章流程模型

第一章使用線性節點，不由玩家選擇正史結果。

```ts
type ChapterNodeId =
  | `scene-${number}`
  | `battle-${number}`
  | 'chapter-complete';

interface ChapterProgress {
  currentNode: ChapterNodeId;
  completedScenes: string[];
  completedBattles: string[];
  activeLineIndex: number;
  selectedStarterWeaponId: StarterWeaponId;
  tutorialStep: string | null;
}
```

規則：

- 初次遊玩不可略過整幕；只能逐句前進。
- 已讀幕可從紀錄重播及整幕略過。
- 每次切換台詞即自動保存 `activeLineIndex`。
- 戰鬥前後建立安全檢查點。
- 戰敗只允許重試或回到戰前準備，不改變正史。
- 戰鬥表現只影響獎勵與角色短評，不影響幕次與結局。

| B5 | 第12→13幕 | 證物轉運護衛 | 奧義、連鎖、舟域援護 |

## 6. 第一個垂直切片

### 6.1 第1幕〈港鐘與舊情〉

- 視點：昭黎。
- 功能：建立昭黎的救難能力、想取得自己船與航照的欲望、洛恩的帶教關係，以及與晏泠的成年舊情。
- AVG 改編保留：拖纜檢查、三船衝突、可交接責任、晏泠重逢、器材櫃繩結。
- 幕末節點：外灣救難鐘響，折蘆出勤。

### 6.2 第2幕〈黑船返航〉

- 視點：晏泠。
- 功能：黑船與兩層潮出現、晏泠因公共風險親手切斷昭黎退路、她主動記錄未申報舊交利益衝突。
- AVG 改編保留：三燈轉紅、長鐘、封港、黑船現身、四號線封閉、救生艇生還者。
- 幕末節點：昭黎取得單次拋纜許可，進入 B1。

### 6.3 B1〈外灣救難線〉

- 固定隊伍：昭黎＋洛恩。
- 不要求四人滿編。
- 第一輪只開放全隊攻擊，提示普攻與敵我回合。
- 第二輪顯示 HP 與受擊。
- 戰鬥結束時解釋勝利、戰敗與重試。
- B1 首次通關消耗 0 AP；重播消耗 5 AP；戰敗退還全部 AP。
- 勝利接到「第3幕尚未實裝」的里程碑完成頁，可重播第1幕或 B1。

## 7. 角色與戰鬥

### 7.1 正式可培養隊員

| 角色 | 元素／定位 | 解鎖時點 |
|---|---|---|
| 昭黎 | 主手武器決定六屬性／固定第一格 | 初始 |
| 晏泠 | 風／控制支援 | 第5幕後 |
| 彌菈·森 | 光／治療 | 第4幕後 |
| 伊嵐 | 土／模型支援 | 第7幕後 |
| 賽芙拉 | 闇／高風險破防 | 第16幕任務加入、第20幕永久加入 |
| 韓澤 | 火／前鋒與後備 | 第24幕後 |

洛恩為早期客座，晦岑為 NPC／顧問。

### 7.2 編隊

- 正式戰鬥為四人隊伍。
- 昭黎固定第一格。
- 其餘三格由玩家從已解鎖正式隊員中選擇。
- B1 是特例，使用昭黎＋洛恩兩人固定隊伍。
- B2 使用昭黎＋晏泠＋彌菈三人固定隊伍。
- B3 伊嵐加入後正式開放四人編隊。

### 7.3 昭黎屬性

- 昭黎不具有固定元素。
- 主手武器決定火、水、土、風、光、闇之一。
- 普攻、奧義、元素標記與相剋計算都跟隨主手。
- 兩個艦長技能維持跨屬性通用。
- 戰鬥中不可更換主手。
- B1 準備畫面提供六把入門主手；美術缺少時使用元素色 fallback 卡。

### 7.4 保留的 RPG 系統

- 每名角色兩個技能與冷卻。
- 普攻、100%奧義及多人奧義連鎖。
- 火、水、土、風、光、闇六屬性相剋。
- 主手與3×3副武器盤。
- 角色及武器 Lv.1–10。
- 首領 Normal／Overdrive／Break。
- 戰鬥快照與重試。
- 原「召喚」在敘事與 UI 改稱「舟域援護」，底層機制不變。

## 8. AVG 系統

### 8.1 劇本命令

劇本資料需支援：

- 背景與色調。
- 左、中、右最多三名演員。
- 服裝、表情、明暗、進場及退場。
- 震動、淡化、閃白與霧氣。
- 事件 CG。
- BGM、環境音與音效。
- 戰鬥插入與檢查點。

### 8.2 玩家控制

- 下一句與上一句。
- 自動播放。
- 已讀快轉。
- 已讀整幕略過。
- 對話紀錄。
- 文字速度。
- 隱藏 UI。
- 劇情紀錄重播。
- 當前說話者提亮並前移；非說話者降低亮度。
- 未讀快轉預設禁止，可在設定明確開啟。

第一個里程碑實作逐句前後、已讀略過、對話紀錄、三人舞台與說話者強調；自動播放、文字速度及 UI 隱藏可在同一基礎上逐步補入。

## 9. 基礎音訊

建立不依賴實際音檔的音訊控制層：

- BGM 單曲播放、停止與交叉淡化。
- 環境音循環。
- 一次性 SFX。
- Master、BGM、Ambience、SFX 四組獨立音量。
- 首次使用者互動後解鎖瀏覽器音訊。
- 缺少音訊檔時靜默略過，不中斷劇情。
- 劇本以音訊 Asset ID 發命令，不直接寫死檔案路徑。

- 成年確認後直接進入昭黎第1幕，不出現艦長性別選擇。

- B1 首通為0 AP、重播5 AP、戰敗全退。
