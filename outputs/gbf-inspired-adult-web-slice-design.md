# 原創成人向艦隊 RPG：網頁垂直切片設計規格

- 版本：1.0
- 日期：2026-08-03
- 狀態：已完成分段設計審核，等待書面規格確認
- 目標平台：Windows PC 瀏覽器
- 技術方案：React、TypeScript、Vite、CSS 動畫

## 1. 產品目標

製作一個約 20–30 分鐘的單機網頁垂直切片，驗證以下完整循環：

1. 選擇成年男性或女性艦長。
2. 觀看序章並進行一次固定免費十連招募。
3. 組成四人隊伍並理解六屬性。
4. 編輯主手武器與九把副武器的武器盤。
5. 完成陸地教學戰與海上大型 Boss 戰。
6. 獲得關係進度並解鎖私人艙室。
7. 解鎖一名角色的成人事件、CG、服裝與展示獎勵。
8. 在結尾收到來自星空的未知訊號，建立後續宇宙篇伏筆。

遊戲只借鑑屬性編隊、武器盤、回合戰鬥、奧義連鎖及角色事件等玩法結構，不使用《碧藍幻想》的角色、名稱、劇情、美術、音樂、商標或原始素材。

## 2. 第一版範圍

### 2.1 納入內容

- 兩種成年艦長外觀選擇；兩者共用主線資料，稱謂與少量角色反應依選擇切換。
- 四名明確成年的女性隊員。
- 火、水、風、土、光、闇六屬性的完整資料規則。
- 一次固定免費十連招募演出。
- 四人前排隊伍、角色技能、被動、奧義與奧義連鎖。
- 一主手＋九副武器的十格武器盤。
- 兩個召喚核心；每場戰鬥只能使用一次召喚。
- 一場陸地教學戰與一場海上 Boss 戰。
- 四階段關係進度、私人艙室與回憶圖鑑。
- 一名角色完整做到關係 Lv.1–3；另外三名展示資料結構與鎖定項目。
- 本機自動存檔、匯出、匯入與重置進度。
- 成人內容的完整顯示、淡出替代與隱藏縮圖設定。

### 2.2 第一版不做

- 帳號、伺服器、雲端同步或多人連線。
- 現金付款、付費抽卡或商店後端。
- 真正的多人 Raid；大型 Boss 只呈現單機 Raid 感。
- 自由移動地圖、即時動作戰鬥或 3D 場景。
- 語音、複雜骨骼動畫或大量角色內容。
- 正式發行平台整合與成就系統。

## 3. 世界觀與序章

故事從成熟的人類地表文明開始。港都正在開發能穿越深海與高空的遠征技術，探索隊於海底遺跡中發現無法由現有文明解釋的訊號。序章以港都及沿岸任務建立世界，海上 Boss 戰揭示訊號並非來自海底，而是由宇宙回傳。

長期世界進程分為四個階段：

1. 地表文明與港都衝突。
2. 海洋、深海遺跡及航海遠征。
3. 月球、軌道殖民地與太陽系探索。
4. 星際文明、遠古訊號與宇宙航行。

### 3.1 序章節奏

| 段落 | 內容 | 目標時間 |
|---|---|---:|
| 艦長選擇 | 選擇成年男女艦長、18+ 確認、序章開場 | 2 分鐘 |
| 固定十連 | 取得第四名隊員、武器與艙室禮物 | 3 分鐘 |
| 編隊教學 | 認識四個職能與六屬性 | 3 分鐘 |
| 陸地教學戰 | 港都防衛、技能與奧義教學 | 4 分鐘 |
| 武器盤 | 主手、九副武器與技能加總 | 3 分鐘 |
| 海上 Boss | Overdrive、Break、召喚與預告招式 | 7 分鐘 |
| 私人艙室 | 解鎖首名角色事件及星空伏筆 | 5 分鐘 |

## 4. 角色與隊伍

艦長的兩種外觀都設定為 25 歲。四名隊員的顯示名稱由資料檔控制，程式內以固定 ID 連接美術與事件。

| ID | 年齡 | 屬性／職能 | 戰鬥定位 | 故事定位 |
|---|---:|---|---|---|
| `CHR_01` | 28 | 火／先鋒 | 單體爆發、破甲、替隊友承傷 | 港都防衛官 |
| `CHR_02` | 27 | 水／術師 | 護盾、潮汐控制、削減模式條 | 海洋工程師；第一版完整關係線 |
| `CHR_03` | 24 | 風／支援 | 加速、連擊、奧義充能 | 遠征飛行員 |
| `CHR_04` | 31 | 光／治療 | 治療、淨化、弱點分析 | 外星生物研究醫師 |

男女艦長皆可進入相同關係線。主要事件結構共用，稱謂、代名詞及少量互動反應使用條件文字切換，避免第一版劇本量翻倍。

## 5. 技術架構

### 5.1 前端

- Vite 建置 React＋TypeScript 單頁應用。
- 畫面使用 React 元件；戰鬥角色、Boss 與 UI 透過分層 WebP、SVG 及 CSS 動畫呈現。
- 路由不是網址頁面，而是遊戲狀態內的有限畫面狀態：標題、序章、招募、編隊、武器盤、戰鬥、結算、私人艙室、回憶及設定。
- 所有繁體中文文字由 HTML 顯示，不烘焙在生成式 UI 圖片中。

### 5.2 資料

角色、武器、召喚、敵人、招募池、戰鬥、故事、事件條件及獎勵使用分離的 JSON 或 TypeScript 資料模組。圖片只透過穩定的資產 ID 連結，因此替換角色名稱、立繪或 CG 不需修改戰鬥核心。

主要資料邊界：

- `characters`：角色屬性、技能、被動、奧義、顯示文字及資產 ID。
- `weapons`：武器屬性、基礎數值、技能及主手效果。
- `summons`：召喚效果、冷卻限制與演出資產。
- `enemies`：行動表、模式條、預告招式與掉落。
- `events`：前置條件、對白、CG、獎勵及內容顯示等級。
- `recruitPool`：固定十連結果及完整版可擴充的隨機池欄位。
- `gameState`：艦長、隊伍、武器盤、資源、戰鬥狀態、關係進度與收藏旗標。

### 5.3 存檔

- 使用 `localStorage` 儲存單一版本化存檔。
- 每次招募、戰鬥結算、武器盤確認、事件解鎖及設定變更後自動存檔。
- 提供 JSON 匯出與匯入。
- 事件解鎖在播放前寫入，播放完成後再標記為已觀看。
- 存檔損壞時保留原始內容供匯出，不自動覆寫；玩家可選擇開始新遊戲。

## 6. 戰鬥系統

### 6.1 隊伍與技能

- 四名角色同時在前排；第一版不設後排替補。
- 每名角色有普通攻擊、兩個主動技能、一個被動及一個 100% 奧義。
- 玩家可在攻擊前任意順序使用可用技能。
- 同回合兩至四人施放奧義時觸發奧義連鎖，造成額外傷害並累積艦隊共鳴值。
- Boss 危險招式提前一回合顯示名稱與目標範圍。

### 6.2 回合流程

1. 玩家技能階段。
2. 選擇普通攻擊或全隊防禦。
3. 結算角色行動、奧義與連鎖。
4. 結算敵方行動。
5. 更新持續狀態、技能冷卻與 Boss 模式條。

### 6.3 六屬性

- 火剋風、風剋土、土剋水、水剋火。
- 光與闇互相形成優勢。
- 優勢傷害乘數為 1.25；逆屬性傷害乘數為 0.75。
- 第一版玩家角色為火、水、風、光；土與闇由敵人及武器展示。

### 6.4 Boss 模式

Boss 依序進入 Normal、Overdrive 與 Break。造成傷害會推動模式條；Overdrive 強化敵方招式，Break 暫停危險行動並增加玩家輸出窗口。海上 Boss 具有三個預告招式及一次階段轉換。

### 6.5 敗北

- 顯示主要敗因、敵人剩餘生命及建議調整項目。
- 保留隊伍與武器盤，可立即重試。
- 不扣除資源。
- 首次敗北只寫入對應特殊事件旗標，供回憶圖鑑使用。

## 7. 武器盤與召喚

### 7.1 武器盤 UI

採用成熟的資訊層級，但使用完全原創的美術：

- 左側獨立放大主手武器。
- 右側九把副武器排列為 3×3 矩陣。
- 頂端集中顯示總生命、總攻擊與預估傷害。
- 下方顯示武器技能加總、武器庫、全部卸下及推薦編成。
- 點擊武器槽時，武器庫由右側滑入；平時不佔據盤面。
- 召喚核心位於同畫面的獨立頁籤，不與武器矩陣同時顯示。

### 7.2 武器內容

- 提供 12 把可用武器，讓十格武器盤存在最低限度的取捨。
- 主手決定艦長屬性、普通攻擊演出及奧義效果。
- 副武器提供基礎攻擊、生命及被動技能。
- 推薦編成依目標屬性及預估傷害選出十把武器。
- 提供兩個召喚核心；每場戰鬥只能選擇一個並使用一次。

## 8. 招募與收藏

- 序章開始時已有三名劇情隊員。
- 固定免費十連必定取得第四名隊員；其他結果為武器及私人艙室禮物。
- 固定結果確保每次測試都能進入相同編隊與劇情流程。
- 完整版可加入隨機池、保底及重複角色碎片，但不屬於第一版。
- 重複角色若日後實作，轉換為只解鎖服裝、姿勢及收藏外觀的「記憶資料」，不形成必要戰力。

## 9. 成人養成與私人艙室

所有可攻略角色明確設定為成年人。成人養成是可選收藏層，不是主線通關所需戰力。

### 9.1 四階段關係進度

| 階段 | 解鎖內容 |
|---|---|
| Lv.1 相識 | 人物檔案、一般對話 |
| Lv.2 信任 | 替換服裝、個人事件 1 |
| Lv.3 親密 | 成人事件入口、CG 回憶 1 |
| Lv.4 專屬 | 私人艙室姿勢、特殊對白；第一版只顯示鎖定結構 |

關係點數來自共同出戰、贈禮、私人艙室對話及指定戰鬥條件。首次敗北與特定狀態可產生獨立收藏旗標，但不扣資源或強迫觀看內容。

### 9.2 第一版成人收藏

`CHR_02` 提供三個成人向收藏入口：關係 Lv.3 主事件、特殊狀態事件及敗北事件。正式 CG 由使用者依美術規格提供；缺圖時使用具名安全佔位圖。

### 9.3 顯示控制

- 首次啟動需要確認已成年。
- 完整顯示：載入正式成人 CG 與事件文字。
- 淡出替代：保留解鎖、獎勵與事件摘要，跳過圖像展示。
- 隱藏縮圖：回憶清單不顯示成人縮圖，但保留文字標題與鎖定狀態。

## 10. 視覺與 UI

### 10.1 視覺方向

以「旭日遠征＋深淵訊號」為主軸：

- 港都、招募及一般選單使用象牙白、海軍藍、黃銅與明亮天空色。
- 深海遺跡及 Boss 戰轉為深藍、青色生物光與警戒紅。
- 星空伏筆加入冷色星光，保留黃銅作為人類文明的視覺識別。

### 10.2 戰鬥畫面

採全螢幕戰鬥舞台型。Boss 名稱、生命及模式條位於上方；角色卡與技能位於下方；危險招式預告置於舞台中央但不遮擋角色。編隊、武器盤及私人艙室使用全畫面覆蓋層進入。

### 10.3 圖像模型分工

圖像生成工具用於製作港都、深海、星空、招募及艙室背景，以及黃銅／青光裝飾、稀有度框與屬性徽章。功能文字、按鈕狀態、鍵盤焦點、數值與版面全部由 React、HTML、CSS 及 SVG 建立，避免生成圖片內文字失真。

## 11. 美術整合介面

使用者負責成年角色、艦長、武器、召喚、敵人、Boss 及正式成人 CG。Codex 負責 UI 視覺資產、背景、互動元件、WebP 轉檔及程式整合。所有精確尺寸、檔名與預期路徑見同目錄的 `art-production-spec.md` 及 `art-asset-checklist.csv`。

## 12. 錯誤處理

- 啟動時驗證角色、武器、敵人、事件及招募資料。
- 缺少圖片時顯示符合目標比例的佔位圖及缺失資產 ID。
- 無效技能目標、冷卻中技能或無法裝備的武器以停用狀態顯示具體原因。
- 事件鎖定項目顯示明確條件，不使用無法測試的模糊提示。
- 瀏覽器無法使用 `localStorage` 時進入無存檔模式並顯示警告；遊戲仍能在本次分頁完成。
- 未處理錯誤由頂層錯誤畫面攔截，提供重新載入、匯出存檔及開始新遊戲選項。

## 13. 測試與驗收

### 13.1 自動測試

- Vitest：屬性乘數、技能冷卻、狀態結算、Boss 模式、武器盤加總、推薦編成及事件條件。
- React Testing Library：招募、編隊、武器替換、私人艙室、設定及錯誤狀態。
- Playwright：男女艦長各一次完整流程、勝利流程、敗北重試、重新整理續玩、存檔匯入、缺 CG 及三種成人顯示模式。

### 13.2 視覺測試

驗證 1280×720、1440×810 與 1920×1080 三種桌面尺寸。戰鬥、3×3 武器盤、私人艙室、回憶圖鑑及對話不得出現文字重疊、按鈕不可見或主要人物被 UI 遮蔽。

### 13.3 完成條件

- `npm run build` 成功。
- 自動測試全部通過。
- 瀏覽器主控台沒有未處理例外。
- 男女艦長都能完成招募、編隊、武器盤、兩場戰鬥、私人艙室與回憶解鎖。
- 敗北重試、重新整理續玩、缺圖佔位及成人內容顯示設定可用。
- 完整流程沒有阻斷問題。

## 14. 後續擴充順序

完成切片後，依序擴充：

1. 增加土與闇玩家角色及更多武器盤選擇。
2. 加入隨機招募、保底及更多收藏獎勵。
3. 增加單機 Raid Boss、後排角色及自動戰鬥。
4. 展開深海篇，建立前往軌道與月球的劇情。
5. 評估桌面封裝、正式發行平台與存檔遷移。
